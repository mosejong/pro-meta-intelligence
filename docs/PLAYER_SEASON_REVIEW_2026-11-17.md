# 연간 선수 자료 검토

현재 선택 가능한 43팀의 219개 원팀·선수 ID를 대상으로, 보관 승인 원본의 2026년 관측을
실제 경기 역할별로 나눴다. 이름이나 다른 팀 이력을 자동 합산하지 않는다. 선수의 전체 경력이나
모든 프로 경기를 확보했다는 주장은 아니다. 원본 취득은 11/11이고 최신 유효 경기는 11/10이므로
이후 경기와 결승이 포함되지 않는다.

## 근거

- 원본 SHA-256과 보관 meta를 확인하고 정규 adapter·기존 출처 정책 gate를 사용했다.
- 파생 JSON 1,126,532 bytes. 모든 219개 프로필 연결, 원본 전체 9,262 유효/642 제외.
- 독립 집계: 역할·범위 678개, 픽 20,099개, 고유 경기 3,235개, 패치·리그 분해 일치.
- 완전한 연간 관측 목록과 최근 역할별 20경기, 현재 참조 패치 기록을 별도로 표시한다.
  다른 역할에서 뛴 횟수를 배정 역할로 옮기지 않는다. 역할 무표본과 선수 자료 미확인을 구분한다.
- 초기 화면에서는 요청하지 않고 펼칠 때만 별도 파일을 읽는다. source/basis/version/size와
  기간·부분집합·분모를 검사한다. 실패·닫기·팀/자료 교체 시 기존 밴픽/로스터를 유지한다.

## 검사 기록

- 모델 초기 검사는 원본 생성 전이었다. 최종 검증은 Codex가 생성한 실제 파일을 포함했다.
- Python 312/312, 웹 118/118(0 skip), Pages 4/4, 타입·린트·ruff 검사/포맷 통과.
- 최초 긴 Windows 임시 경로 실패를 보존했고, 짧은 새 임시 경로에서 전체 검사를 통과했다.
- 실제 Chrome PC·모바일 폭에서 `/draft/`의 실제 파일 로드·역할별 수치 대조와
  합성 자료의 전환/선수 이동/밴/되돌리기/누락·불일치·늦은 응답까지 8/8 통과했다.

## 범위와 다음 연결

현재 기능은 관측 근거 표시다. 추천 가중치·실력·승률·시뮬레이션 엔진에 연결하지 않았다.
기존 저장 v2/v3, 로스터 v1, A/B 형식을 바꾸지 않았다. 번역/새 API/네트워크 수집도 없다.

수동 재생성: `python ops/build_player_season_history.py --season 2026`.
새 승인 보관 원본은 `--csv`, `--meta`로 명시하고 원래 취득 시각을 유지한다.
현재 파일은 참조 feed basis에 고정된다. 피드 갱신 후에는 기존 자동 갱신 job의 승인 원본으로
연간 파일도 재생성하는 연결 코드는 후속 작업에서 완료했다(`PLAYER_SEASON_REFRESH_RESULT.md`).
아직 서버 반영 전이며, 실패하면 불일치를 숨기지 않고 연간 표시를 거부한다.
실제 휴대폰·타 브라우저·시뮬레이션 효용·2027 전이 성능을 검증한 것은 아니다.
