# 한국어 지인 테스트판

2026-11-18 사용자 결정: 한국어판을 먼저 만들고 수강생 동료·지인에게 사용 의견을 받는다. 이후 중국어판과 홍보를 검토한다. [메인 문서](PROJECT_MASTER_PLAN.md) · [개발일지](DEVELOPMENT_LOG.md)

## 테스트 범위

로그인 없이 팀 선택 → 모의 밴픽 → 선수/시즌 구성 → 구단 저장/복원 → 근거와 A/B 입력 비교 → 팀·밴픽 링크 공유를 사용한다. 현재 구현 범위에서 가능한 흐름만 안내한다. 과거 시즌 선수는 별도 구단 구성으로 보관하며 실제 승률·A/B 선수 효과·경기 시뮬레이션에는 반영하지 않는다. 구단/선수/시즌은 현재 공유 링크에 포함되지 않는다.

기존 중국어 선택 기능을 삭제하지 않되 한국어를 기본 테스트 언어로 삼고 새 기능의 중국어 번역 완료를 주장하지 않는다. 현재 선수 기록은 공식 최신 소속을 보장하지 않는다.

실시간 방은 로컬 서버 검증만 완료했다. 별도 운영 서버가 없는 정적 배포본은 기존 팀·밴픽 링크 공유를 제공하며 실시간 대전이 가능하다고 안내하지 않는다. 로그인·기기 간 구단 저장·실제 경기 승패 예측·구도별 룬/아이템 추천도 테스트판의 완료 기능이 아니다.

## 배포 전 확인

1. 시즌 참조와 구단 v1/v2의 호환·중복·손상·오류 시 보존 검사.
2. 타입/린트, 전체 웹, Pages 빌드 및 실제 시즌 집계의 해시·카드 수 검증.
3. PC·모바일 폭에서 선택·저장·복원·취소·자료 실패 재시도와 기존 구단 회귀.
4. 최신 main 통합 뒤 자료 기준/출처가 뒤섞이지 않는지 확인. 원시 CSV·개인 자료·키가 배포되지 않는지 명시적 파일 목록을 확인.
5. 정적 배포 성공 뒤 실제 서비스 URL에서 기본 화면·자료 파일·한국어 흐름 확인. 로컬 성공을 배포 성공으로 대신하지 않음.
6. 테스트 링크는 공개 URL일 수 있다. 지인에게만 전달한다고 인증된 비공개 서비스라고 설명하지 않음. 사용자가 지인에게 공유하며 에이전트가 연락을 보내지 않음.

## 지인에게 부탁할 사용 흐름

1. 설명을 읽기 전에 양 팀을 고르고 밴픽을 시작해 본다.
2. 챔피언을 선택해 확정하고, 되돌리기와 다음 세트 잠금을 확인한다.
3. 선수·로스터 탭에서 구단을 저장한 뒤 새로고침하고 다시 불러온다.
4. 과거 시즌 자료를 열어 2022 Nuguri 같은 선수를 구성하고 기록/미확보 안내가 이해되는지 본다.
5. 밴픽 링크를 다른 창에서 열고, 무엇이 공유되는지 확인한다.

완료를 강요하지 않는다. 막힌 지점과 혼동한 표현이 주요 결과다. 실제 휴대폰 검사는 별도로 부탁하며 모바일 폭 에뮬레이션과 구분한다.

## 받을 피드백

- 휴대폰/PC, 브라우저와 문제가 난 화면.
- 처음 1분 안에 무엇을 해야 하는지 알았는가?
- 어디에서 멈췄고 무엇을 예상했는가?
- 저장·복원·공유 범위가 예상과 같았는가?
- 선수 기록과 가상 결과를 실제 능력/승률로 오해했는가?
- 다시 쓴다면 어떤 상황에서 쓰겠는가?
- 개선 하나만 고르면 무엇인가?

스크린샷은 필요한 화면만 받고 계정·연락처·개인 전적 같은 불필요한 개인정보를 요구하지 않는다. GitHub 가입이나 JSON 업로드를 피드백 조건으로 만들지 않는다. 현재 자동 이용 계측은 검증하지 않았으므로 첫 라운드는 사용자에게 전달되는 수동 의견으로 기록한다.

## 지인 공유 문구 초안

> 롤 모의 밴픽·구단 구성 사이트를 만들고 있어요. 한국어 테스트판이라 써보고 막히거나 헷갈리는 곳을 알려주면 도움이 됩니다. 로그인 없이 시작할 수 있고, 구단은 이 브라우저에 저장돼요. 선수 기록을 살펴보는 기능이며 실제 경기 승률이나 완성된 경기 시뮬레이션은 아직 제공하지 않습니다. https://mosejong.github.io/pro-meta-intelligence/

이 문구는 초안이며 전송하지 않았다. 11/18 실제 배포 주소의 PC·모바일 폭 확인을 마친 뒤 링크를 입력했다. 이후 배포에서는 주소가 같아도 반영 버전과 기능을 다시 확인한다.
