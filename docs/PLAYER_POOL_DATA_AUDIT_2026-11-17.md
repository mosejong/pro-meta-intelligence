# 선수 풀 자료 범위 확인

현재 `web/public/feed/current.json`: 패치 16.20, 기준 시각 2026-11-14T00:19:10.467435+00:00.
43팀 모두 선수 프로필을 포함하고 총 219개(CURRENT 215, OTHER_OBSERVED 4)다.
팀당 최대 10경기이며 선수 챔피언 목록은 `brief.py::_player_profiles`에서 상위 4개로 제한된다.
154개 프로필에서 목록 경기수 합이 선수 전체 표본보다 작다. 이는 목록 누락이지 0회 관측이 아니다.
최근 경기 세부 목록은 42팀에 없다. 특정 팀의 상세 자료를 다른 팀에 대입하면 안 된다.

중요: 선수 프로필의 role은 최신 관측 역할(없으면 최빈 역할)이며 챔피언 횟수는 해당
선수의 전체 선택 기록을 합산한다. 따라서 role이 배정 역할과 같더라도 프로필 챔피언 횟수를
그 역할에서만 사용한 횟수라고 표시할 수 없다. 역할별 세부 근거는 별도로 확인해야 한다.

이번 UI 연결은 공개 스냅샷의 제한된 요약을 따른다. 올해 전체 선수 성향이나 전체 남은
챔피언 폭을 확보했다고 하지 않는다. 다음 자료 확장은 로컬 승인 원본의 연간 관측 기록을
선수 ID/역할/시점/패치별로 분리하고, 요약 제한과 자료 누락을 명시하는 별도 계약이 필요하다.
이는 새 외부 수집·API 활성화 승인이 아니다.
