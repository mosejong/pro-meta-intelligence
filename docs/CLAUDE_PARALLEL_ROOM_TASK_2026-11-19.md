# 병렬 B: 친구 방 재시작 복원
Claude Opus 5.5 medium. 기존 메모리 DraftRoomStore를 보존하고 명시 opt-in인 로컬 파일 영속 백엔드(단일 프로세스)로 서버 재시작 후 같은 방과 권한/멱등성을 복원한다. 외부 계정/서버/구매/배포 없음. 기존 HTTP/링크/브라우저 계약은 유지한다. 소유파일만 필요한 만큼 읽는다.
소유: web/server/draft-room-store.ts, web/server/draft-room-http.ts, web/server/run-draft-room.ts, 신규 web/server/draft-room-persistence.ts, 신규 web/tests/draft-room-persistence.test.mjs, 신규 web/tests/draft-room-persistence-http.test.mjs, docs/CLAUDE_PARALLEL_ROOM_RESULT_2026-11-19.md. 기존 테스트는 읽기 전용. package.json/클라이언트/다른문서 수정금지.
필수: 기본은 ephemeral 그대로. runner 환경변수 DRAFT_ROOM_STATE_FILE이 있을 때만 파일 사용. 검증된 source/feed identity가 같은 경우만 복원; 손상/스키마/기준 불일치/불법draft/권한/만료는 fail-closed하고 원본 파일을 덮어쓰지 않는다. 유효 방과 멱등성 action ID를 보존, 만료는 연장하지 않는다. 원자적 임시파일+rename, 저장 실패는 성공 응답/notify/메모리 mutation을 남기지 않도록 transactional 구현한다. TTL sweep도 적절히 보존. 파일 크기/방/행 수 제한. 파일·토큰이 공개 경로나 snapshot/log에 노출되지 않는다. 파일은 서버 전용 민감 credential 보관임을 문서에 명시, POSIX 0600/Windows ACL 한계. 암호화/분산 DB/다중 writer 지원을 꾸미지 않는다. 경로가 public/dist/정적배포 아래면 거부. health storage는 실제 모드에 맞춘다. 복원 검증에서 public report와 기존 드래프트 검증기를 재사용한다.
관련 unit 및 실제 HTTP 재시작 테스트만 실행. 특히 재시작 후 기존host/guest/spectator 권한과 잘못된token, revision conflict, 요청 중복/id재사용, 손상, 쓰기 실패 rollback, 만료/feed변경 테스트. fullnpm/build/브라우저/네트워크/설치/깃/다른에이전트 금지. 복잡해 안전하게 못 끝내면 구현중단 지점과 한계 명시. 토큰한도 우회금지.
