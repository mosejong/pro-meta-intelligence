# 시즌 선수·구단 저장 연결 결과

2026-11-18. 한국어 지인 테스트판 준비 배치. 이 기록 시점은 최신 main 자료 통합과 공개 배포 전이다.

## 연결 범위

- 확보한 원본만 사용해 2022/2026년 1,184개 선수·시즌·팀·역할 카드를 생성한다. 원본 CSV나 실제 선수 능력치는 배포하지 않는다.
- 과거 시즌 자료는 사용자가 열 때만 같은 origin에서 내려받고, 역할·선수·당시 팀·표본·미확보 연도를 구분한다.
- 카탈로그의 구조·출처·합계와 콘텐츠/카드 ID 해시를 확인한다. 해시는 무결성 확인이며 외부 서명이나 원본 권리 승인 증거는 아니다.
- 시즌 선수 배정은 현재 슬롯을 비우며, 현재/시즌/상대의 같은 선수 ID 중복을 거부한다. 시즌을 해제해도 이전 선수를 자동 복원하지 않는다.
- 구단 v2에 카탈로그/카드/선수 ID 참조를 저장한다. v1은 읽을 수 있고 쓰기 때만 v2로 보존한다. 자료 버전이 다르면 자동 치환하지 않는다.
- 시즌 선택은 현재 로스터 파일·공유 링크·A/B 선수 효과·경기 시뮬레이션에 포함하지 않는다. 기존 로스터 파일은 시즌 선정을 해제한 뒤 사용할 수 있게 해 조용한 정보 유실을 막는다.
- 파생 파일을 명시적 공개 자산 목록과 Git 예외 목록에 넣었다. 자동 자료 갱신 workflow에 이 새 카탈로그 재생성을 붙이지는 않았다.
