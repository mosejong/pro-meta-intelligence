# 사용자 구상 원본 요약 — 제품·사업 검토의 필수 입력

대화에서 사용자가 직접 요청한 내용을 정리했다. 시장 조사 결과나 구현 완료 목록이 아니다.
우선순위 충돌 시 아래 최신 지시와 실제 사용자 메시지를 우선한다.

## 최근 확정 지시

- T1 저격 목적을 종료한다. T1 전용 메뉴·기본 타깃을 없애고 모든 팀을 동등하게 선택한다.
- 기능 구현·검증이 먼저다. 완성된 기능이 생기면 번역 담당 에이전트를 별도로 붙인다.
- 한국어·중국어 간체까지 갖추고 충분한 완성도(사용자 표현 90% 이상)에 이른 뒤 공개를 고려한다.
  이는 예측 적중률 90%를 요구한 것이 아니다. 체감 완성도는 검증 가능한 출시 조건으로 구체화한다.
- 공개 후 국가별 트래픽을 파악하고 서버·도메인 구매와 각국 홍보를 판단한다.
- Claude Fable 최고 추론으로 깊게 검토하고 Codex와 토론한다. 사용자는 초기화권을 적용했다고 알렸다.
- 자율 구현·검증은 진행하되 비용·계정·이용 권한·공개 결정이 필요할 때 사용자에게 묻는다.

## 출발점과 분석 가치

아래 T1 출발점은 초기 요구의 이력이다. 현재 제품에 특정 팀 우선 고정을 요구하는 뜻이 아니다.

1. T1을 위한 상대 밴픽 분석에서 시작했다. 밴픽 단계에서 유리한 출발을 돕고 실제 인게임은 선수가 한다.
2. LCK뿐 아니라 상대 리그와 국제대회도 분석한다. 월즈 경기만 보지 말고 올해 전체 경기를 봐야 한다.
3. 선수별 주력 챔피언·선택 성향을 놓치지 않는다. 특정 서포터의 시즌 레오나 선호 같은 기록을 찾고,
   최근 메타와 시즌 주력을 구분한다. 다른 팀에서도 검증해야 한다.
4. 감독 성향도 반영하고 싶다. 현재 자료로 선수·팀·코치의 효과를 구분할 수 있는지는 검증 과제다.
5. 사용자가 실제 효용을 믿을 수 있게 입증해야 한다. 에이전트 교차 평가 후 사람 평가도 고려한다.
   에이전트 간 합의나 테스트 통과만으로 실제 밴픽 우위가 입증되지는 않는다.

## 홈과 모의 밴픽

6. 첫 화면은 긴 설명 대신 모의 밴픽 창이다. 나와 상대가 각각 팀을 고른다. T1에 고정하지 않는다.
7. 선택한 챔피언의 정보·룬·아이템을 곁에서 보고 자세한 분석은 상세 탭에 둔다.
8. 친구끼리·스트리머가 간편하게 이용할 수 있어야 한다. 양쪽 직접 조작과 향후 원격 방·관전·공유를 구분한다.
9. 시각 디자인은 양산형 AI 랜딩페이지를 피한다. 참고 사례와 별도 디자인 담당, 실제 캡처 검토를 원한다.

## 빌드·구도 분석

10. 챔피언만 같다고 빌드가 같지는 않다. 상성·조합·역할·게임 구도에 따라 핵심 코어와 룬을 비교하고 싶다.
11. 사용자에게는 Knight의 Akali 빌드 인터뷰 논쟁이 계기였다. 그 발언의 원문·경기·시각은 확보 전까지
    검증된 사실이나 특정 선수의 실수로 취급하지 않는다. 관측 빌드·발언·분석 가설을 분리한다.

## 장기 핵심: 감독형 분석 시뮬레이션

12. 밴픽을 끝내면 근거들을 모아 실제 경기처럼 시간 흐름이 있는 가상 경기를 돌려보고 싶다.
13. FIFA Online과 Football Manager의 차이처럼, 직접 캐릭터를 조작하기보다 선수 특징·선택·전략을 시험한다.
14. 감독은 픽을 계속 수정하고 결과가 어떻게 달라지는지 비교한다. 승패 판정이 있는 확장도 원한다.
15. 단순히 승자를 먼저 정하고 해설을 만드는 것이 아니라, 상태와 사건에서 결과가 나오는 모델이 목표다.
    모델 내 결과와 검증된 실제 승리 확률은 구분한다.
16. 이름은 아직 미정이다. '롤 매니저'는 비유이며 제품명이나 Riot의 공식 제품임을 뜻하지 않는다.
17. 사용자는 LoL을 복제한 직접 조작 게임보다는 분석 시뮬레이터로 생각한다.
    명칭만으로 실제 기능과 데이터 이용 범위의 검토가 끝났다고 간주하지 않는다.

## 연중 이용·개인화

18. 월즈가 끝나도 스토브리그에 로스터·선수 교체 실험을 하고 싶다.
19. 개인 전적을 연결해 성향표/선수 카드를 만들고 싶다. 예: 야스오 장인이 야스오를 잡으면 결과가 바뀌나?
20. 나머지 조건이 같을 때 다이아 원딜 대신 마스터 원딜을 넣으면 모델 결과가 달라지는지도 궁금하다.
21. 개인 연습 데이터도 활용하고 싶다. 공개/동의 자료와 비공개 스크림을 구분하고, 접근 가능 범위를 확인한다.
    티어·개인 승률을 프로 실력 또는 보편적인 숨은 실력 수치로 곧바로 치환하지 않는다.

## 사업 방향

22. 웹 서비스 이용자를 모으고 광고 수익으로 운영하고 싶다. 현시점 유료 구독 사업으로 전환을 승인한 것은 아니다.
23. 한국뿐 아니라 중국도 중요한 대상이며 중국어판과 중국 사이트 홍보를 염두에 둔다.
24. 먼저 완성도를 높인다. 공개·홍보·국가별 이용 측정 후 인프라 투자 순서이며 지금 구매하지 않는다.
25. 수요·트래픽·광고 단가·성능 우위·법적/데이터 권한이 이미 확인됐다고 가정하지 않는다.

## 검토자가 해야 할 일

이 모든 구상을 단순 기능 목록으로 칭찬하지 말고, 핵심 이용 동기·반복 이용·검증 가능성·자료 접근·
계산 비용·차별성·단계별 투자 의사결정으로 연결한다. 당장 구현할 것과 실험으로 확인할 것을 구분한다.
우선 타깃과 기능 순서에 이견이 있으면 사용자 방향을 몰래 변경하지 말고 근거와 선택지를 제시한다.
