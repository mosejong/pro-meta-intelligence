# 룬·아이템 연결 · 다음 구현 관문

기존 [API 조사](API_DATA_RESEARCH_2026-11-17.md)와 [시뮬레이션 계약](SIMULATION_DATA_CONTRACT.md)을 대체하지 않는 후속 점검이다. 11/18 공식 문서와 로컬 허용 범위를 대조했다. 제품 수집/키/출처 등록은 변경하지 않았다.

## 재확인

- Riot [공식 LoL 문서](https://developer.riotgames.com/docs/lol#items)는 Data Dragon의 아이템 설명·가격·조합식·능력치 정적 데이터를 안내한다. 이것은 특정 경기의 구매 순서나 프로 선수 선택 근거가 아니다. 현재 사이트의 최신 패치와 과거 경기 패치를 자동으로 같다고 간주하지 않는다.
- 공식 [API 목록](https://developer.riotgames.com/apis)은 동적 Reference다. 이번 조회에서 최신 Match-V5 전체 DTO를 검증하지 못했다. 구매·되돌리기·판매 처리나 대회 경기 접근 범위를 확인했다고 쓰지 않는다.
- 저장소의 Data Dragon 허용 작업은 버전/챔피언뿐이다. 아이템·룬 수집 작업은 아직 등록되지 않았다. Riot Web API는 REVIEW_REQUIRED/허용 작업 없음이다. 새 API를 켜거나 솔로랭크 보류 결정을 바꾸지 않았다.
- 기존 OE 자료/현재 집계는 실제 구매 순서·상황별 완성 빌드의 근거가 아니다. 골드·챔피언만으로 사용한 빌드를 추정해 관측으로 저장하지 않는다.

## 진행 순서

1. 정적 정보 카드: 특정 패치·언어의 카탈로그 계약, 출처/해시/취득 시각, 없는 아이템·불일치·HTML 설명 정제·이미지 실패 처리를 설계한다. 좁은 신규 작업 범위를 실제 정책 검토 후 등록해야 수집/연결한다.
2. 경기 관측: 권한 있는 실제 프로 경기/동의 계정 샘플을 확보한 뒤 경기·선수 ID·패치·역할·상대 구도·구매 시각·최종 장비·되돌리기를 분리한다. 접근 가능한 샘플 없는 프로 경기 범위는 미지원이다.
3. 구도별 비교: 표본과 누락을 표시하고, 관측한 선택과 사용자가 설정한 계획을 분리한다. 낮은 표본으로 최적 코어/승률 개선을 주장하지 않는다.
4. 시뮬레이터: 기존 엔진이 실제 아이템 패시브·룬 효과를 계산하지 않으면 미적용으로 표시한다. 정적 능력치나 선수 인터뷰만으로 효과를 넣지 않는다.

현재 자율 진행 범위는 설계·기존 근거 대조까지다. 신규 출처/허용 작업 활성화는 기존 출처 경계를 확장하는 별도 결정으로 남긴다. 이 관문 때문에 과거 자료 수용과 기존 연습 기능 보완을 중단하지 않는다.
