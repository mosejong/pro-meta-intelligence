# 혼자 밴픽 → 리포트 → 다시 도전

2026-11-18. 사용자: 공유보다 실제 기능·흥미를 더 만든 뒤 테스트한다. 이 배치는 로컬 구현이며 신규 배포/홍보/지인 연락은 하지 않는다.

## 이번에 연결한 기능

`상대 자동 밴픽`을 켜고 내 진영을 고르면 내 차례만 직접 조작한다. 상대는 실제 턴마다 현재 공개 우선 픽/레이더를 참조하고, 기록 후보가 소진되면 고정 목록의 연습 선택을 사용한다. 모두 남은 유효 챔피언인지 확인하고 이미 고른/밴한/피어리스 잠금 챔피언을 재사용하지 않는다. 팀 기록·레이더·목록 대체의 이유를 구분한다.

규칙 기반 연습 상대이며 실제 팀의 전략이나 실력을 예측하지 않는다. 관측 역할은 중복 역할을 피하는 힌트만 쓰며 자동 역할 확정이나 조합 승률이 아니다. 인간 양쪽 조작은 기본값으로 유지한다.

- 자동 상대 중에는 사용자 확정을 잠근다. 다른 탭·초기화 확인 창에서는 자동 진행을 멈춘다.
- 내 마지막 선택으로 되돌리면 뒤따른 상대 선택도 함께 걷어낸다.
- 새로고침/파일·공유 입력 복원 때 자동 모드는 꺼진다. 다른 사람의 입력을 계속 자동 조작하지 않는다.
- 친구 방에서는 자동 모드를 끄고 비활성화한다. 서버 확정 상태와 로컬 자동 상대를 섞지 않는다.
- 20턴 완료 뒤 공개 기록과 대조한 리포트를 보여주고 혼자 모드에서는 그 위치로 이동한다. 다시 도전은 기존 확인 창을 거치고 다음 세트는 피어리스 잠금을 재사용한다.

## 리포트의 의미

양 팀 픽 5개, 양쪽 우선 픽 요약에 겹치는 확보 카드, 상대 우선 픽 중 실제로 밴한 카드, 남겨둔 우선 카드의 상태를 보여준다. 여러 역할의 요약 횟수는 합산하지 않고 가장 큰 관측 행을 쓰며 근거 ID를 보존한다. 기록이 없으면 미확인이다. 챔피언/선수/감코 효과·조합 시너지·실제 승패나 우열 점수를 만들지 않는다.

입력 20턴과 규칙/챔피언/피어리스 잠금을 재검증한 뒤에만 리포트를 만든다. 미완료나 불법 입력에는 부분 결과를 꾸미지 않는다. 지원하지 않는 완료 입력에는 선택을 유지하고 안내한다.

## 구현·검증 기록

순수 자동 선택/리포트 로직은 별도 에이전트가 각각 파일 2개씩 구현했다. 부모가 UI·실제 진행·저장과 통합했다. 별도 읽기 전용 검토에서 방 참여가 개인 자동 저장을 덮는 문제를 찾아 active-room 동안 자동 저장을 제외했다. 명시적 나가기 뒤 마지막 방 보드를 개인 복사로 저장하는 동작은 유지한다.

최초 새로고침 브라우저 검사는 화면 확정만 보고 내구 저장을 기다리지 않아 1턴 대신 0턴으로 복원됐다. 저장 완료를 확인한 뒤 새로고침하도록 고치고 다시 검사한다. 이 실패를 임의 지연으로 숨기거나 저장 안전장치를 완화하지 않는다.
