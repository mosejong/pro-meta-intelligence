# 일반 이용자용 밴픽 공유·화면 정리

2026-11-18 사용자 요청: JSON 대신 쉬운 공유, 기존 도구의 다른 톤 정리, 벨코즈 이미지 수정.
기능 구현 에이전트2개와 부모 통합 검증으로 진행했다. Claude 실행으로 표현하지 않는다.

## 바뀐 동작

- 기본 공유는 **밴픽 링크 복사**다. 팀·진영·확정 밴픽·올려놓은 챔피언·완료된 이전 세트를 URL fragment로 전달한다. 파일 선택·로그인·새 서버 없이 현재 상태를 주고받는다.
- 링크는 동시 접속 방이 아니라 상태 복사본이다. 선수 변경·역할 배정·A/B 기준·개인 연습·전체 분석 보고서는 포함하지 않는다. 이 범위를 복사 버튼 앞과 수신 미리보기에서 알린다.
- 받는 쪽의 현재 공개 자료와 같은 패치에서 팀·챔피언·순서·피어리스 잠금을 다시 검증한다. 자료 시각이 바뀌어도 발신 당시 분석을 재현한다고 주장하지 않는다. 다른 패치/없는 팀/알 수 없는 챔피언이면 거부한다.
- 수신 링크는 미리보기만 표시하며, 기존 밴픽이나 기기 저장을 자동 교체하지 않는다. **이 밴픽 불러오기**를 눌러야 바뀐다. 취소는 기존 작업을 보존한다. 미리보기 도중 공개 자료가 바뀌면 최신 자료로 재확인한다.
- 모바일에서는 수신 미리보기로 이동·초점을 맞춰 불러오기 버튼이 화면 안에 보인다. 긴 분석 시각은 접힌 공유 기준에 둔다.
- 클립보드가 거부되면 선택해서 복사할 수 있는 입력칸을 제공한다. 늦은 복사 완료가 수정 후의 새 밴픽을 복사했다고 표시되지 않도록 결과를 입력에 연결했다.
- 이전 파일 저장/불러오기는 **고급 설정**에 남긴다. 기존 파일 형식과 읽기 검증은 유지한다. 초기화는 기본 화면에 남겨 일반 이용자가 파일 도구를 열 필요가 없다.
- 상단은 모의 밴픽과 접힌 연구 자료로 정리했다. 기존 팀 분석·레이더·콘텐츠·검증 경로와 작업 기능은 보존하고 공통 헤더·기본 바탕·글꼴·모바일 하단 메뉴를 차콜 톤으로 맞췄다. 기존 개별 분석 시각화를 전면 재설계한 것은 아니다.
- 벨코즈 `Vel'Koz`/`VelKoz` → `Velkoz`, 벨베스 `Bel'Veth`/`BelVeth` → `Belveth`를 공식 Data Dragon 파일명으로 연결했다.
- 공식16.16.1 목록에서 도출한173개 챔피언 이름/ID를 고정 반례로 두어 모든 이름과 정식 ID의 이미지 연결을 검사한다. 아이콘 버전은 통계 패치나 챔피언 효과를 갱신하는 것이 아니다.

## 검증

- 웹 전체187/187 통과. 최초185통과·2실패는 의도한 legacy-workspace 클래스 추가를 옛 렌더 검사가 받아들이지 않아서였으며, 실제 새 구조를 확인하도록 수정했다. 렌더 전용42/42 재검사 후 전체187/187도 통과했다.
- TypeScript·전체 ESLint 통과. 최종 공유 초점/표현 보완 후에도 재검사했다.
- Pages 빌드·검사4/4 통과(최종 초점/표현 포함).
- PC·모바일폭22개 고유 조작 흐름 확인. 첫 실행20통과·2실패는 동일 fragment 주소 재이동을 새 문서 방문이라고 본 테스트 기대였다. 명시적 새로고침으로 새 방문/저장 복원을 구분한 뒤2/2 재통과했다.
- 최종 공유·메뉴·실제 이미지12/12, 이후 미리보기 버튼 화면 노출/초점을 보완한 공유8/8도 통과했다. 각 실행의 실제 통과 수를 합산해 새로운 고유 사례 수처럼 쓰지 않는다.
- 실제 공식 CDN에서 벨코즈·벨베스 이미지가 complete/naturalWidth>0인지 PC·모바일폭으로 확인했다.
- 기기 저장 후 취소·재방문·명시적 교체, 클립보드 거절과 늦은 완료, 잘못된 링크, 현재 선수 기록의 지연·실패·재시도·자료 범위·밴/되돌리기·늦은 응답을 확인했다.
- 기본 sandbox가 로컬 소켓을 막아 첫 UI 실행을 소유한 exec 세션으로 중단하고, 허용된 로컬 서버 실행 경로로 검사했다. 임의 PID 종료나 설정 변경은 하지 않았다.
