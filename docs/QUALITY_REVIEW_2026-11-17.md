Claude Opus 5.5 Medium은 공개 피드 로더를, Codex는 연간 로더와 교차 검토를 맡아 파일을 분리했다.

## 아직 없는 기능 — 결함 수정과 구분

- 로스터 변경은 선수 관측/남은 풀 표시만 바꾼다. A/B 파일은 로스터 효과·경기 승패를 계산하지 않는다.
- 실제 게임처럼 상태·사건을 진행하는 최소 시뮬레이터는 아직 없다. 입력/규칙/시드 계약부터 필요하다.
- 구도별 룬·핵심 코어 추천은 관측 자료와 접근 범위를 확보하지 않았다.
- 친구와 같은 기기 양 팀 밴픽과 JSON 공유는 가능하지만 원격 방·동시 접속은 구현하지 않았다.
- 감독 효과, 개인 연습 데이터, 중국 실기 접속, 실제 사람의 효용 평가는 검증하지 않았다.
