# 2027 LoL 스토브리그 출처 경계 검토

기준: **2026-11-19 KST**. 당일 시각은 지정되지 않아 일자만 고정하며, 당일 모든 발표를 확인했다는 뜻은 아니다. LCK·LPL 우선 수동 웹 연구이며 자동수집 등록용 파일이 아니다. 원문 페이지를 저장하지 않고 요약·링크만 기록했다.

## 사실

검토표 12건 중 **플랫폼 미러 경유 공식 발표 내용 열람 8건**, 언론보도 3건, 루머 1건. 공식 원문 직접 검증은 0건이다. 미러 열람 기록은 농심 계정 게시물에 집중되어 있으며 리그 전수 현황이 아니다. LPL의 2027 변화에 관해 직접 검증한 공식 발표는 0건이다. 이는 발표가 없다는 뜻이 아니다.

8건의 등급을 **OFFICIAL_CONTENT_VIA_PLATFORM_MIRROR**로 정정한다. Sina에서 NS_RedForce 공식 계정 인증 문구·게시자·발표 본문을 실제 읽은 기록은 보존하지만, 원래 Weibo permalink와 공식 원문을 직접 검증한 것은 아니다. 기존 source URL·요약·날짜·source_access는 삭제하지 않았다. JSON의 confirmed는 원문 직접 검증 기준으로 false로 정정했다. 언론 제목이나 현황판의 Confirmed 배지는 공식 원문 직검 근거가 아니다.

**원래 Weibo permalink 미검증·신원 stable ID 미연결·프로덕션 채택 금지.** 모든 항목은 연구 검토 전용이며 자동등록·소속 갱신·로스터·프로덕션 사실 카드에 채택하지 않는다. 부모의 독립 web open에서 Sina 2건/Sheep Esports 1건 접근 실패로 재현되지 않았다는 사용자 보고를 기록했다. 개별 실패 URL은 전달되지 않아 특정 행에 배정하지 않으며, 접근 실패를 자료 부재나 과거 열람 부재로 해석하지 않는다.

## roster-scenario.ts 읽기 검토와 연결 제안

- `web/app/roster-scenario.ts:7`: CURRENT는 스냅샷 관측값이며 공식 현재 소속이 아니다. 팀 ID·선수 ID가 식별 기준이고 이름은 표시용이다.
- 115~139행: 유일하고 비모호한 CURRENT 관측만 기본 슬롯에 놓는다. 177·212행: 스냅샷에 없는 선수는 UNKNOWN_PLAYER로 거절한다.
- 165행: virtual은 다른 팀/포지션 이동 여부만 계산한다. 실제 복귀·공식 소속 검증값으로 사용할 수 없다. notCurrent와도 분리되어 있다.
- 238행: 가상 로스터는 분석·추천·시뮬레이션에 반영되지 않는다는 경계문이 있다. 259행: cutoff·패치·출처 버전이 다른 파일을 거절한다.

연결안: 관측 스냅샷과 별도 이적 이벤트 계층에 발표 URL·실제 발표일·대상 시즌·효력일(null 허용)·등급·역할·안정 ID 매핑을 보존한다. 미러 8건 및 B/C는 모두 검토대기에 두고 프로덕션 사실 카드·CURRENT·로스터에 채택하지 않는다. 신원 stable ID는 아직 연결하지 않았다. 향후 공식 원문 직검과 ID 연결을 별도 완료한 뒤 채택 여부를 검토하며, 관측 포지션을 덮어쓰지 않는다. 계약종료→FA/입단/선발, 에이전시 계약→복귀를 자동 추론하지 않는다. 감독·코치는 5개 선수 슬롯과 별도 저장한다. 너구리처럼 현재 스냅샷에서 확인되지 않는 역대선수는 v1 ID 검증을 우회해 주입하지 않고, 필요하면 별도 버전의 사용자 가정으로 설계한다. **이번에는 데이터 연결이나 코드 변경을 수행하지 않았다.**
