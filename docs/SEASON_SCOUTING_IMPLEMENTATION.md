# 시즌 선수 성향과 진행 중 드래프트 연결

시즌 기록은 `target.season_tendencies`로 생성한다. 최신 공개 경기의 선수 ID·역할을 기준으로
분석 컷오프 이전 같은 연도의 경기 전체를 모으며, 이전 팀 기록도 포함한다.
선수 ID가 없으면 이름으로 추정해 합치지 않고 근거 부족으로 표시한다.

포지션별 화면은 다음 정보를 구분한다.

- 시즌 사용 횟수: 예상 픽 상위 목록에서 밀려도 삭제하지 않는다.
- 최근 사용 횟수: 현 팀 최근 최대 40경기 중 해당 선수가 출전한 경기 기준이다.
- 선택률 차이: 최근 비율에서 시즌 비율을 뺀 값이다. 두 표본이 겹치며, 독립적인 전후 비교는 아니다.
- 예상 픽: 기존 선수 기록·포지션 메타 순위를 유지한다. 시즌 성향만으로 예측 가중치를 변경하지 않는다.

확정된 현재 밴·픽과 이전 세트 픽은 `buildDraftScoutBrief`에 전달한다.
현재 연습의 양 팀 ID가 팩의 T1·상대 ID와 일치할 때만 잠금을 적용하며 진영 교환도 지원한다.
다른 팀 스카우팅을 볼 때는 잠금을 섞지 않는다. 되돌리기로 선택을 취소하면 후보는 복원된다.
조합 카운터나 역할 확정은 아직 추론하지 않는다. 플렉스 챔피언을 특정 역할로 단정하지 않는다.

7팀 자료는 기존 2026-11-04 수집 CSV로 재생성했다. 데이터 수집일을 오늘로 바꾸지 않았다.
이번 구현은 시즌 성향 노출과 후보 가용성 갱신이며, 예측 정확도 향상을 새로 입증한 작업은 아니다.
밴·피어리스 선택 기회 보정, 조합 교환 시뮬레이션, 감독 재임 기간 정보는 후속 작업이다.
