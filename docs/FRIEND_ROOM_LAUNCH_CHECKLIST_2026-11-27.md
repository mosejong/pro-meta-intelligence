# 친구 방 공개 운영 준비 체크리스트 · 2026-11-27

[#164](https://github.com/mosejong/pro-meta-intelligence/issues/164) P2 준비 문서. 기존 방 서버·클라이언트를 그대로 운영하기 위한 점검표이며 새 서버를 만들지 않는다. 외부 가입·키·구매는 하지 않았고, 아래 "사용자 결정" 칸은 실행하지 않은 항목이다. 관문 표기는 충족/미충족/미확인만 쓴다.

## 1. 지금 있는 것 (코드·로컬 검증 기준)

| 구성 | 위치 | 상태 |
|---|---|---|
| 방 서버(Node HTTP, NDJSON 구독) | `web/server/draft-room-{http,store,persistence}.ts`, 진입 `run-draft-room.ts` | 로컬 동작. `127.0.0.1`에만 바인딩 |
| 방 클라이언트·화면 | `web/app/draft-room-*.ts(x)` | `VITE_DRAFT_ROOM_ENDPOINT`가 없으면 방 만들기 버튼 대신 준비 안내 |
| 권한 | 방장=블루, 초대 첫 참가자=레드, 관전 링크=읽기 전용. 방장 토큰은 공유 링크에 없음 | 로컬 e2e로 확인 |
| 제한 | 방 2시간 만료, 최대 200방, 방당 구독 24, 본문 16KiB, IP당 시간당 생성 10회 | 코드 기본값 |
| 영속화 | `DRAFT_ROOM_STATE_FILE` 지정 시 파일 1개(단일 writer). 공개 폴더 경로 차단 | 선택 기능, 기본은 메모리 |
| 상태 확인 | `GET /health` | 있음 |
| 검사 | 방 전용 e2e `npm run test:room:e2e`(방 서버 포함) 8/8, 서버 단위 `npm run test:room` | 2026-11-27 `d08a115` 기준 e2e 8/8 통과 |

기본 `npx playwright test`는 방 주소 없이 빌드하므로 `draft-room` 4종×2가 항상 실패한다(방 만들기 버튼이 없음). 방 검사는 반드시 방 전용 설정으로 본다.

## 2. 공개 전에 고쳐야 할 코드 (외부 계정 없이 가능)

| # | 항목 | 이유 | 상태 |
|---|---|---|---|
| C1 | 프록시 뒤 실제 사용자 IP로 생성 제한 | 지금은 `request.socket.remoteAddress` 기준. 공개하려면 HTTPS 프록시가 앞에 서므로 모든 사용자가 프록시 IP 하나로 보여 **전체 합산 시간당 10방**이 된다. 신뢰할 프록시를 명시한 경우에만 지정 헤더를 읽는 옵션 필요 | 미충족 |
| C2 | Pages 빌드에 방 주소 연결 | `pages.yml`은 `VITE_CLOUD_SAVE_URL`만 저장소 변수에서 넣는다. 같은 방식으로 `VITE_DRAFT_ROOM_ENDPOINT`를 변수로 받게 하고, 변수가 없으면 지금처럼 준비 안내 유지 | 미충족 |
| C3 | 자료 갱신과 방 서버 패치 일치 | 서버는 시작 시 `current.json`을 한 번 읽는다. 사이트 자료가 하루 4번 갱신되면 서버·화면의 패치·기준 시점이 어긋날 수 있다. 진행 중 방은 기존 자료로 끝내고 새 방부터 새 자료를 쓰는 재적재 방식 필요 | 미충족 |
| C4 | 연결 끊김·만료 안내 문구 점검 | 만료(2시간)·서버 재시작 시 사용자가 보는 문구와 "혼자 연습으로 이어가기" 경로를 운영 조건에서 재확인 | 미확인 |
| C5 | 운영 로그 최소화 | 방 토큰·상태 파일 경로는 이미 로그 제외. 요청 IP 보관 범위(제한용 메모리만, 저장 안 함)를 개인정보 안내에 맞춰 확정 | 미확인 |

## 3. 사용자 결정이 필요한 것 (실행 안 함)

| # | 결정 | 선택지 | 비고 |
|---|---|---|---|
| U1 | 방 서버를 어디서 돌릴지 | (a) 무료 Node 호스팅 + HTTPS(장시간 스트리밍 연결 허용 여부 확인 필요) (b) 기존 계획대로 Cloudflare Workers + Durable Objects로 이전(코드 재작성 큼, 무료 한도는 가입 시 확인) (c) 공개 보류, 링크 공유만 유지 | 비용 원칙: 무료 등급만, 결제수단 등록 금지([구성안](ACCOUNT_AND_CLOUD_SAVE_PLAN_2026-11-23.md)) |
| U2 | 공개 주소 | `*.workers.dev` 또는 호스팅 기본 주소. 도메인 구매 안 함 | CORS 허용 목록(`DRAFT_ROOM_ALLOWED_ORIGINS`)에 `https://mosejong.github.io`만 |
| U3 | 방 상태 영속화 | 메모리(재시작 시 방 사라짐) vs 파일(단일 인스턴스 전용) | 다중 인스턴스면 파일 영속화 불가 |
| U4 | 운영 책임 | 장애 알림 받을 곳, 되돌릴 버전 | 현재 감시 워크플로는 방 서버를 보지 않음 |
