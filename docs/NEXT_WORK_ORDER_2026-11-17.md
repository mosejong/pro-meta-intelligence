# 범용 밴픽 제품 작업 순서

2026-11-17 사용자 결정: T1 저격 목적을 종료하고 특정 팀에 고정되지 않는 밴픽·분석·
감독형 시뮬레이션 제품으로 진행한다. T1도 다른 팀과 똑같이 선택 가능한 데이터다.
메뉴 삭제를 위해 과거 경기나 검증 근거를 지우거나 다른 팀 자료로 바꾸지 않는다.

## C0 — 특정 팀 고정 해제 (구현·검증 완료)

- T1 브리프 메뉴·기본 타깃·우선 고정과 T1 전용 대회 준비실을 일반 흐름에서 제거한다.
- 기존 /t1/ 링크는 범용 팀 분석으로 연결한다. 저장한 팀 선택은 유효하면 유지한다.
- 임의의 두 팀에서 밴픽·저장·복원·A/B 비교가 동작해야 한다.
- 완료 근거: 웹/Pages/타입/린트, 양 언어 메뉴에 전용 링크 없음, PC/모바일 폭에서
  새 기본값과 기존 저장 자료 호환성 점검. 과거 T1 팩의 직접 검증은 보존한다.

## C1 — 가상 로스터와 포지션 배정

2026-11-17 PR #121로 구현·배포 완료. 로스터/선수 효과가 엔진에 연결됐다는 뜻은 아니다.

첫 구현 범위는 [로스터 작업 지시](CLAUDE_ROSTER_FIRST_TASK.md)로 고정했다.
기존 밴픽 파일은 유지하고 작은 로스터 전용 파일로 편집·저장·복원을 먼저 완성한다.
분석/비교/시뮬레이션 입력으로 연결하는 계약 변경은 그 뒤 별도 검증한다.

- 두 팀의 관측 선수를 보여 주되 공식 최신 로스터라고 단정하지 않는다.
- TOP/JUNGLE/MID/BOTTOM/SUPPORT 슬롯에 선수를 선택·교체하고 가상 변경을 표시한다.
- 선수 식별·자료 기준 시각·관측/공식/가상 상태를 분리한다. 역할을 챔피언 이름만으로 확정하지 않는다.
- 범위가 검증된 뒤 저장·복원·A/B 내보내기 계약에 버전을 추가한다. 기존 v2/v3 파일은 호환 경로를 유지한다.
- 완료 근거: 중복/빈 슬롯/잘못된 파일·교체·되돌리기·새로고침·버전 호환, 실제 UI 검사.

## C2 — 시즌 성향과 피어리스 풀 장부

첫 배치에서 현재 관측 선수 근거·남은 목록 연결을 로컬 구현했다. 자료 범위는
[현재 선수 자료 확인](PLAYER_POOL_DATA_AUDIT_2026-11-17.md)과 [구현/검사 기록](PLAYER_POOL_RESULT.md)을 따른다.
다음 배치로 [연간 역할별 관측 자료 연결](PLAYER_SEASON_REVIEW_2026-11-17.md)을 로컬 완료했다.
11/11 승인 보관 원본에서 현재 219프로필의 연간/최근20/참조패치를 구분하며 추천 점수에는 미반영이다.
기존 피드 갱신 workflow에 이 파생 파일 생성을 연결하는 코드와 실패 보존 검증도 로컬 완료했다.
[갱신 검토 결과](PLAYER_SEASON_REFRESH_RESULT.md)를 따르며, 실제 서버 예약 실행 확인은 머지 후 남는다.
특정 팀 전용 팩을 다른 팀 근거로 사용하지 않는다.

- 해당 선수·해당 팀·시즌/최근/패치별 표본과 출처를 분리해 보여 준다.
- 현재 배정 포지션과 선택 챔피언의 경험, 이전 세트 잠금과 남은 관측 풀을 대조한다.
- 자료 없음과 0회 관측을 구분하고, 외부 팀 기록이나 T1 전용 팩을 일반 근거로 섞지 않는다.
- 완료 근거: 여러 팀, 선수 교체/동명이인, 플렉스, 별칭, 과거 기준 시점, 잠금 소진 반례.

## C3 — 시뮬레이션 입력 계약과 최소 엔진

- 로스터·역할·밴픽·전략·빌드 계획·패치·모델/자료 버전·시드를 고정한다.
- 지원하는 작은 상태 전이(성장/자원/교전/오브젝트/종료)에서 사건과 승패가 나온다.
- 같은 입력·시드의 재현성, 종료·자원·시간 불변식, 진영 교체와 가정 민감도를 검사한다.
- 사용자 가정과 관측에서 온 값을 구분한다. 모델 내 결과를 실제 승률로 표시하지 않는다.
- 관측 룬·아이템 자료와 사용 권한이 확보되면 별도 검증 후 연결한다. 가짜 추천으로 채우지 않는다.

## 공통 원칙

2027 시즌 변경 대응은 [공식 발표 조사 및 버전 분리 계획](SEASON_2027_READINESS.md)을 따른다.
1월 개편과 뉴 던 출시는 별개이며, 미발매 수치는 구현하지 않는다. C1을 지연시키지 않고
C2 근거 분리, 빌드·룬 연결, C3 규칙 버전 관문 순서에 반영한다.

기능 구현·검증이 먼저이고 번역은 완료한 기능에 별도 담당을 붙인다. 추가 Fable 토론은
하지 않는다. 구현은 Opus 5.5 Medium, Codex는 범위 설정·검토·통합을 담당한다.
각 배치의 결과와 미확인을 기록하고 다음 배치를 진행한다. 공개·구매·외부 계정 활성화는 별도 결정이다.
