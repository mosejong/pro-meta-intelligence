# 연도별 역사 자료 수용 검사 · Codex 독립 검토

구현: Claude Opus 5.5 medium / 독립 검토: Codex. 신규 공급자 요청·제품 배포 없음.

## 구현과 교차 검토

- `ops/audit_player_career_archive.py`는 기존 원본 검사와 career builder를 재사용하는 오프라인 도구다. 연도별 미확보·cutoff 이후 취득·무결성/정책 차단·유효 표본 없음·일부 제외/수용을 구분한다. 같은 연도 여러 버전의 충돌은 기존 규칙대로 제외한다.
- Codex 독립 검사에서 `--output`을 원본 보관 폴더 내부로 지정하면 원본 폴더를 수정하면서 `archive_modified=false`를 출력하는 결함을 재현했다. Claude가 정규화·링크 해석 경로를 검사해 폴더 생성 전 차단하도록 수정했다. 독립 회귀 검사는 유지했다.
- 최종 독립 Python 전체 **477개**, ruff 검사·포맷 **113개 파일** 통과. Windows sandbox 하드링크 권한으로 실패한 초기 검사는 정상 권한/임시 경로에서 다시 실행했다. Claude 완료 보고를 독립 실행으로 대체하지 않았다.
- 도구의 종료 코드 0은 진단 생성 완료이며 모든 연도 수용을 뜻하지 않는다. `status_counts`와 개별 상태를 읽어야 한다. 신규 공개 데이터 계약/전체 연도 완성/승률/실력/은퇴 판단 도구가 아니다.

## 실제 보관 자료 읽기 전용 검사

고정 cutoff `2026-11-18T14:05:00+00:00`, 원본 변경 없음. `outputs/career-admission-real-20261118.json`.

| 연도 | 수용 경기 | 제외 경기 | 상태 |
| --- | ---: | ---: | --- |
| 2022 | 11,804 | 715 | USABLE_WITH_REJECTIONS |
| 2026 | 8,581 | 1,386 | USABLE_WITH_REJECTIONS |

나머지 11개 연도는 NOT_DOWNLOADED다. 2026년 5개 원본 버전 사이에서 495개 경기 충돌이 발견돼 기존 보수적인 규칙으로 제외됐다. 현재 시즌 단일 최신 원본의 전체 경기수와 혼동하지 않는다. 로컬 최신 2026 원본은 11/11 취득본으로 서버 최신 피드보다 오래됐다.

정확한 공개 source player ID로 확인한 2022 기록은 너구리 탑 **57경기**, 페이커 미드 **144경기**다. 이는 수용한 자료 안의 관측 수이며 연간 완전성을 보장하지 않는다. 너구리의 2026년 미관측은 UNKNOWN이며 은퇴·실력·사용 경험 없음의 증거가 아니다. 이름으로 자동 결합하지 않았다.
