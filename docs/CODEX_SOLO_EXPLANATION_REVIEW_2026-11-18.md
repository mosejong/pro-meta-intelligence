## 자동 상대 설명

- 직전 자동 선택의 실제 근거를 요약하고 상세에 같은 선택 직전 상태의 합법 대안을 최대 2개 표시한다. 대안은 읽기 전용이며 선택 순서의 이유를 설명한다. 실제 상대 대응·승률 예측이 아니다.
- 공개 우선 픽, 현재 선수, 기준이 맞는 선수 시즌, 레이더, 기록 부족 대체 규칙을 구분한다. 자료 미수신·불일치·선수 미일치는 사용 경험 0회로 표시하지 않는다.
- Codex가 기록 부족·빈 선수 맵·다른 cutoff·요약의 잘못된 근거 주장을 재현해 Claude에 재수정을 요청했다. 독립 회귀 검사 7개를 유지한다.
- 변경 전 확보한 84경기 1,680회 선택(현재/동결 자료, 양 선픽, 피어리스 3세트)과 변경 후 전체 선택 결과가 일치했다. 이것은 동작 보존 검사이며 추천 적중률 증거가 아니다.
- 최종 웹 284개, 타입·lint, Pages 4개 통과. 브라우저는 기존 혼자 연습과 설명 12개 통과 후, 마지막 요약 수정 뒤 설명 4개를 PC·모바일에서 재검사했다. 캡처도 확인했다.
- 설명은 직전 실제 선택의 메모리 기록이다. 세트 전체 원인 이력을 저장하거나 공유하는 기능까지 구현한 것은 아니다.
