# 현재 밴픽 규칙 검증 — Codex 독립 확인 (2026-11-20)

- 기준을 먼저 로컬 커밋 `30525faf`로 고정한 뒤 계산했다. 가중치·후보 수·평가 기간을 결과에 맞춰 바꾸지 않았다.
- 11/4 보관본을 입력, 11/11 보관본을 결과 확인용으로 사용했다. 새로운 자료 요청은 하지 않았다. 원본 해시와 실제 보관 시각을 검증했다.
- 조건에 맞는 첫 세트는 9경기(LAS·WLDs), 밴·픽 180차례다. 후보 3개씩 540개에서 이미 사용했거나 알 수 없는 챔피언 추천은 0개였다.
- 실제 선택과 1순위가 같은 경우: 밴 5/90, 픽 6/90, 전체 11/180(6.1%). 후보 3개 안에 실제 선택이 있는 경우: 밴 7/90, 픽 18/90, 전체 25/180(13.9%).
- 이 수치는 **선수 시즌 자료를 연결하지 않은 경로**의 제한된 진단이다. 이번 경로에서는 `seasonHistory=null`이며 실제 전체 제품 성능·승률·사용자 효용을 의미하지 않는다. 선수 시즌 성향 0건을 선수 성향이 없는 것으로 해석하지 않는다.
- 현재 시즌 전체 또는 독립적인 미공개 평가가 아니다. 같은 원본은 이전 연구에도 쓰였으며 경기 내 20차례는 서로 독립 표본이 아니다.
- 제품 사용 가능 상태와 실전 수준의 상대 예측 성능을 구분해야 한다. 높은 완성도 수치나 광고 문구의 근거로 사용하지 않는다.
