# 완료 기준과 현재 상태 (2026-11-11)

기준 출처는 `docs/CLAUDE_HANDOFF_2026-11-11.md`와 사용자 지시(작업 순서 1~5, 2차 지시 1~5)다.
상태는 세 가지로만 표시한다.

- **충족**: 이번 작업에서 실제로 확인함
- **미충족**: 아직 안 됨
- **외부 필요**: 실제 사람 평가, 새 데이터 접근 권한, 머지·배포가 있어야 진행 가능

기준은 결과에 맞춰 낮추지 않는다. 에이전트 점수는 사람에게 유용하다는 증거가 아니다.
상황 테스트와 반례 시나리오의 개수는 규칙 위반을 찾는 검사 범위일 뿐이며, 추천 성능이나 효용의 증거가 아니다.

## 그 밖에 남은 일

- `ops/evaluate_frozen_blg_series.py`는 이제 `--frozen-pack`과 `--pack-sha256`이 필수다.
  해시가 다르거나, 팩 기준 시점이 첫 경기 이후이거나, 출력 파일이 이미 있으면 중단한다.
- 준비 확인 체크 목록의 잠긴 카드에는 이제 "사용 불가 · 확정 밴픽/이전 픽" 표시가 붙는다(11/12, 테스트로 확인).
- 결승 시작 시각은 11/12에 운영자가 확인한 11.15 04:00 KST(11.14 19:00 UTC)로 표시한다. 공식 일정 피드의 같은 시각 항목은 참가팀이 'T1 vs BLG'로 남아 있어 계속 보류한다.
- 통계적 효용은 입증되지 않았고(미충족), 사람 평가(1.15)는 아직 하지 않았다(외부 필요).
- 7팀·분석가 4명이라 같은 팀·같은 분석가 안의 상관이 크다.
  분석가마다 사용 조건 팀 수도 3 또는 4로 조금 다르다.
- 결과를 여러 번 만들어 유리한 것만 공개하는 것은 코드로 막을 수 없다. 외부 사전등록에 의존한다.
