# 밴·오픈·선점 비교

현재 T1–상대 연습 대진이 스카우팅 팩과 일치할 때 교환 비교 패널을 표시한다.
관측된 상대 역할별 후보 하나를 선택하면 세 가지 가정을 나란히 보여 준다.

- 밴: 검토 카드를 양 팀 후보에서 제외하고, 상대의 남은 같은 역할 후보와 우리 대안을 표시한다.
- 오픈: 상대가 검토 카드를 가져간다고 가정한다. 우리 대안에는 같은 카드를 넣지 않는다.
- 선점: 같은 역할의 우리 공개 기록과 수동 준비 확인이 모두 있을 때만 확보 검토 카드로 표시한다.

확정 밴·픽, 이전 세트 피어리스 픽을 모두 제외한다. 선픽 팀과 진영은 별도로 전달한다.
현재 우리 밴 차례에는 밴, 우리 픽 차례에는 준비 확인된 선점만 즉시 가능한 행동으로 표시한다.
오픈은 드래프트 행동이 아닌 계획용 가정이다. 어떤 분기도 실제 드래프트를 자동 변경하지 않는다.

준비 확인은 패널의 일시적인 로컬 React 상태이며 네트워크·공개 피드·시나리오 파일로 보내지 않는다.
상대를 바꾸거나 페이지를 다시 열면 초기화된다. 실제 팀 연습 기록을 자동 수집했다고 표시하지 않는다.

## 범위

이는 같은 역할의 관측 후보와 기회비용을 비교하는 기능이다. 전체 조합 시뮬레이션,
카운터 상성, 최적 밴 계산, 최종 픽 확보, 승률 향상을 입증한 모델이 아니다.
상대 후속 후보는 조건에 맞는 기존 순위이며 실제 다음 선택을 보장하지 않는다.
다른 역할과의 조합·플렉스 배정·다음 차례 상대 밴은 아직 계산하지 않는다.

## 검증

진영 교환·레드 선픽, 우리 차례 여부, 현재 및 과거 픽 잠금, 준비 미확인,
역할이 다른 준비 입력, 근거 없는 검토 카드, 오픈 시 양 팀 중복 확보 방지,
원본 드래프트 불변성과 기본 준비 상태를 자동 테스트한다.
새 테스트는 기본 `npm test`에 포함해 CI에서도 실행된다.
