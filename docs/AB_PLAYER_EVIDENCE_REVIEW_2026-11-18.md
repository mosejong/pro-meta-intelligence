# A/B 선수·챔피언 관측 근거 — 부모 검토

사용자 승인 범위: 역할 배정/선수 기록을 연결하고 A/B 차이를 출처 있는 관측값으로 설명한다. 새 승률·실력 가중치·네트워크 수집·배포는 하지 않는다.

## 독립 대조 (구현 중 완료)

- v2 writer가 아직 있을 때 실제로 `serializeDraftComparison`으로 파일을 생성해 보관했다. 이후 새 reader로 다시 읽어 v2/로스터를 보존하고 역할은 null임을 확인했다.
- 파일 1,362,639bytes, SHA256 `42a63d5f08cadeda5d55cdbac4071188b7ae3e1bd54e4371ca9527f332d752b5`. 위치 `outputs/ab-evidence-20261118/frozen-schema2.json`, 원본 메타데이터 별도. 새 v3 파일의 필드만 지워 옛 형식이라고 한 검사가 아니다.
- 실제 연간 집계에서 현재 report에도 ID가 있는 한 선수를 골라 TOP에 가상 배정하고 검증된 드래프트/로스터를 만들었다. A/B에서 배정 챔피언 2개를 바꿔 6개 범위(연간/최근/패치 각각 A/B)의 분자·분모를 원 JSON과 직접 대조했다.
- 연간 관측 챔피언 목록에서 **이전·현재의 양 팀 픽만** 직접 집합 연산했다. helper의 nextSetLocks/nextSetPool은 기대값 계산에 사용하지 않았다. 다음 세트에는 현재 밴이 돌아오는 것, 남은 개수는 같지만 멤버가 달라지는 것(새 잠금/다시 열림) 모두 일치했다.
- source parser와 draft validator는 공유했다. 독립된 데이터 원본/선수 효과 입증이라고 부르지 않는다.
- 증거 `outputs/check-ab-evidence-independent-20261118.mjs`, `outputs/ab-evidence-20261118/independent-review.json`.

## 통합 전 추가 확인

- 미확인 선수의 행을 입력이 같다는 이유로 '같은 행'에 묶으면 경험까지 동일하게 확인한 것으로 오해할 수 있다. UI에서 확인 불가 행을 같은 행과 구분하고 0/동일 판정이 아니라는 문구를 확인한다.
- 현재 준비 입력과 A/B 초안·선수·자료가 달라졌을 때 과거 역할이 B에 붙지 않는지 빠른 사용자 이동으로 검사한다.
- v1/v2/v3 JSON의 역할 null/명시 기록/잘못된 ID·다른 팀 픽·중복 역할을 확인한다.
- 연간 자료는 현재 추가 참고이며 A 고정 당시 자료/내보내기 파일에 보관된 값이라고 주장하지 않는다.
- 부모 타입/린트/단위/Pages 및 PC·모바일 새 UI·관련 기존 회귀를 실제 실행한다. Claude의 작성만 한 검사를 실행 완료로 세지 않는다.

## 완료한 통합 검증

- 미확인/빈 선수 행은 '같은 행'과 별도로 묶고 '0·동일 아님'을 표시하도록 Codex가 보완했다. 해당 행이 같은 행 그룹에 들어가지 않는 실제 UI 검사를 추가했다.
- 새 단위를 기본 runner에 연결했다. 빌드 포함 웹 **180/180**, typecheck/lint, Pages **4/4** 통과.
- 최초 관련 UI 실행은 14통과, 3실패, 15미실행으로 fail-fast했다. 새 검사가 live/replay의 두 표를 같은 선택자로 찾는 문제와 v1 변환 예제에 v3 역할 필드가 남는 문제였다. live 표로 선택자를 좁히고, v1에 원래 없던 역할 필드를 제거하도록 예제를 고쳤다. 실제 v2 파일의 새 reader 검증은 별도로 이미 통과했다.
- 수정 후 PC의 실패 두 사례+실제 자료 대조 **3/3** 통과. 모바일 관련 전체 **17/17** 통과. 처음 통과한 PC14개와 합쳐 **PC·모바일 34개 고유 시나리오**를 확인했다(단일 전체 실행이 한 번에 전부 통과한 것으로 쓰지 않는다).
- 실제 자료 대조는 `/draft/` 하위 경로에서 역할을 명시 배정하고 A를 고정한 뒤 두 역할을 바꾼 B를 만들었다. 실제 파일을 원팀·선수 ID로 직접 조회해 각 역할의 연간/최근/패치 분자·분모와 다음 세트 남은 목록 수를 UI와 독립 대조했다. 기존 helper로 기대값을 다시 계산한 테스트가 아니다.
- 최종 구현에서 독립 순수 계산 및 옛 v2 파일 재현도 다시 통과했다. `outputs/ab-independent-review-final-20261118.log`.
- 실제 자료 캡처: `outputs/ab-evidence-20261118/{desktop,mobile}-real-ab-evidence.png`. 테스트는 비교를 위해 일부러 역할을 바꾼 예시이며 추천 조합이 아니다. 합성 자료 캡처는 `*-fixture.png`로 구분했다.
- 로그 `outputs/ab-evidence-{full-web,typecheck,lint,pages,desktop-final,mobile-final}-20261118.log`. 원본 및 최종 UI 보고서는 `outputs/ab-evidence-20261118/{first-ui-results,desktop-final-results,mobile-final-results}.json`.

## 남은 범위

v3 파일은 역할 배정까지 재현하며 연간 집계 원본·추가 수치는 포함하지 않는다. 추가 수치를 A 고정 당시 근거로 보관했다고 하지 않는다.
다음 세트 풀은 역할별 **관측 목록**의 피어리스 차감이며 실제 선수의 전체 가능 챔피언이나 패치·대회별 금지 목록이 아니다.
현재 자료의 사용 횟수·표본 차이는 선수 효과·숙련도·승률의 검증이 아니다. 새 수집·Python·모델 변경·배포는 없다.
