# 스카우팅 갱신과 상대전·조합 근거

## 운영 문제 수정

기존 hosted OE 수집기는 메타 피드 다섯 파일만 갱신했다. 스카우팅 팩은 빌드에 포함된
고정 JSON이라 최신 경기 수집에 성공해도 갱신되지 않았다.

`ops/refresh_draft_scouts.py --feed web/public/feed/current.json`은 accepted feed의
원본 해시·실제 수집 시각과 정확히 일치하는 검증된 archive snapshot만 사용한다.
추가 네트워크 요청이나 임의의 가장 최신 파일 선택은 하지 않는다. 모든 대상 생성이
끝나기 전에 기존 팩을 변경하지 않으며, 컷오프가 뒤로 가는 갱신은 거부한다.

워크플로는 sync와 health가 통과할 때 이 단계를 실행한다. 실패하면 후속 빌드·배포를
진행하지 않는다. 쓰기 허용 경로에는 기존 다섯 피드와 고정된 7팀 팩만 추가했으며,
원본 CSV·기타 파일·과거 validation.json의 게시 권한은 늘리지 않았다.

로컬 7팀 팩은 11월 11일 02:19:29 UTC 수집본으로 갱신했다. 이전 팩은
`outputs/frozen-scouting-before-20261111`에 파일 해시를 붙여 보존했다. 경기 전 예측을
이 새 팩으로 다시 평가하면 데이터 누수이므로, 사후 채점은 보존본이나 Git의 당시 파일을 사용해야 한다.

## 추가한 분석

- 상대전 1페이즈 밴: 상대가 T1을 만난 실제 경기만 집계한다. 예측 가중치나 밴 의도는 추정하지 않는다.
  최신 BLG 팩은 T1전 10경기이며 룰루 밴 4회가 포함된다.
- 관측 조합: 최근 최대 40경기에서 다른 역할의 두 챔피언이 같은 팀에서 함께 나온 횟수와 경기 ID를 남긴다.
- 교환 비교: 확정 상대 픽 또는 오픈 가정 카드와 함께 쓴 조합을 표시한다.
  밴·선점 분기는 해당 카드가 들어간 상대 조합을 제외한다.
  우리 조합은 이미 고른 카드 또는 역할별 준비 확인이 있는 카드만 표시한다.
  현재 밴픽·피어리스 잠금과 충돌하는 조합은 제외한다.

함께 쓴 두 카드를 보여주는 것은 상성 평가나 상대를 이기는 카운터 추천이 아니다.
봇 듀오를 포함한 실제 사용 근거이며, 전체 5인 조합·역할 배정·인게임 실행은 평가하지 않는다.
과거 70경기의 검증 수치는 갱신하지 않았으며 새 기능의 성능으로 표시하지 않는다.

## 확인

생성 도중 대상 팀이 없으면 기존 파일을 보존하는지, 오래된 입력이 최신 팩을 덮지 않는지,
워크플로 허용 경로, 준비 미확인·잠금 카드가 조합에 들어가지 않는지 자동 테스트한다.
