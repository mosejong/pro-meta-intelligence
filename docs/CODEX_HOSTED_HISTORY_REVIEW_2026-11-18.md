# 과거 자료 서버 수집 · Codex 독립 검토

상태: 로컬 구현·독립 검증 완료. 서버 실행·새 다운로드·배포 없음.

## 요구

기존 서버의 인증된 암호화 보관/복원, 원장, `pages` 동시 실행 그룹을 재사용한다. 기본 예약은 현재 시즌, 수동 과거 자료 모드는 누락된 한 연도만 처리한다. 과거 모드에서는 피드 게시·빌드·푸시·Pages 배포를 하지 않는다.

## 독립 검사

- 가짜 과거 다운로드 실패 후 실제 암호화 보관/복원, 이어지는 현재 시즌 요청이 24시간 원장에 막히는 통합 검사 통과. 외부 요청은 없었다.
- 최초 구현 반례: 복원 보고서 JSON `null`, 실제 원본 없는 빈 archive 폴더가 사전 검사에서 거부되지 않았다. `tests/test_hosted_history_review.py` 독립 회귀 두 개로 재현했다. 원본이 있어야 암호화 재보관 가능하므로 빈 복원도 다운로드 전 차단해야 한다.
- Claude가 두 복원 반례를 수정했고 독립 검사에서 통과했다.
- 추가 결함: 현재 시즌용 진단 업로드가 과거 모드에도 실행돼, 업로드 서비스 오류 시 암호화 재보관을 건너뛸 수 있었다. Claude가 해당 단계를 현재 시즌 모드로 제한했다. Codex는 과거 요청과 재보관 사이 모든 단계가 과거 모드 제외 또는 실패 허용인지 별도로 검사했다.
- 최종 전체 Python **456개**, ruff 검사·포맷 **111개 파일** 통과. YAML 파싱과 Bash **15개 블록 구문 검사** 통과. 셸 블록은 실행하지 않았다. 웹 소스가 바뀌지 않아 이전 웹 284개 결과를 이번 변경 이후 재실행한 것으로 표시하지 않는다.
- 실제 GitHub Actions 조건 판정/서버 실행은 미확인이다. 단위 검사의 조건 시뮬레이터는 GitHub 자체가 아니다. 기본 예약과 수동 기본값은 현재 시즌 유지, 명시 수동 `history_only=true`일 때만 과거 수집으로 분기한다.
- Claude 두 실행 모두 `claude-opus-5-5`, 결과 `is_error=false` 확인. 구현 보고만으로 독립 통과를 선언하지 않고 Codex가 위 검사를 별도 실행했다.

## 결과와 다음 관문

- 공급자 대기 시간 미충족은 `DEFERRED`이며 다운로드 성공으로 표시하지 않는다. 인증 복원 실패·손상·정책 만료는 요청 전 차단한다. 실패 시도는 기존 암호화 보관 경로를 거친 뒤 실행 실패로 보고한다.
- 과거 수집은 현재 시즌과 같은 24시간 예산을 소비하므로 다음 현재 시즌 요청을 늦출 수 있다. 자동 과거 예약은 추가하지 않았다.
- 이 워크플로는 `main`을 checkout한다. 로컬 변경을 승인·통합하기 전에는 서버에서 이 버전을 실행할 수 없다. 공개 제품 배포와 별개로 운영 변경의 실제 실행 확인이 남는다.
- 다음은 최신 서버 원장·로컬 예약 중단 여부를 확인하고 대기 시간 이후 수동으로 한 연도를 확보한 뒤 해시·연도·ID·누락을 검사하는 것이다. 현재 하한만으로 향후 요청 허가를 보장하지 않는다.

## 운영 경계

같은 GitHub 동시 실행 그룹은 그 경로의 서버 작업만 직렬화한다. 로컬 CLI와 임의 다른 워크플로까지 잠그지 않는다. 서버가 수집을 소유할 때 로컬 공급자 다운로드를 중단해야 한다. 공개 수집 상태는 보수적 시각 대조이며 전역 잠금이 아니다.

확보된 로컬 연도는 2022·2026년이다. 다음 우선순위 2015 → 2020 → 2021은 기존 계획을 유지한다. 원본 확보와 선수 역사 자료 정규화·검증·UI 반영은 별도 관문이다.
