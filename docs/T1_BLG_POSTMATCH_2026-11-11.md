# T1–BLG 준결승: 고정된 경기 전 자료 평가

결과 자료는 11월 11일 수집한 OE CSV
`fcd2e451d10fd56271f151a63cf001ed8727935ef4237a34956ab4a1836944de`다.
예측은 `web/app/scouting/t1-vs-blg.json`의 11월 4일 컷오프 자료를 그대로 사용했다.
결과 파일에 팩 SHA-256과 원본 공급자 해시를 기록한다. 새 자료로 예측을 다시 만들지 않았다.

같은 양 팀·시간 범위의 채택 경기 네 개를 확인했고, 실제 BLG 선수 ID는 기존 시즌 성향의
선수 ID와 전원 일치했다. 양 팀 이전 세트 픽을 잠금으로 제외했다.
이 채점은 세트 시작 전 후보이며, 현재 세트의 밴·중간 픽은 입력하지 않았다.

| 항목 | 경기 전체 |
|---|---:|
| 역할별 예상 후보 최대 6개에 실제 픽 포함 | 14/20 (70%) |
| 포지션 메타만: 같은 후보 예산 | 14/20 (70%) |
| 기존 선수 최근 풀 | 11/20 (55%) |
| 예상 후보 1위가 실제 픽 | 2/20 (10%) |
| BLG 1페이즈 밴: 후보 6개 포함 | 6/12 (50%) |
| 주력 제거 검토 목록이 실제 BLG 픽을 포함한 세트 | 1/4 |

## 세트별

| 세트 | T1 결과 | 예상 픽 포함 | 예상 밖으로 분류된 실제 카드 (이전 시즌 사용 횟수) |
|---|---|---:|---|
| 1 | 패 | 4/5 | Viper 코르키 (9) |
| 2 | 승 | 2/5 | Xun 키아나 (5), Viper 카이사 (1), Knight 르블랑 (9) |
| 3 | 패 | 3/5 | ON 나미 (5), Knight 탈리야 (2) |
| 4 | 패 | 5/5 | 없음 |

BLG는 룰루를 1페이즈에 네 번 밴했다. 국제대회 일반 메타 기반 밴 후보만으로는
상대가 이번 T1전에 반복 투자한 밴을 충분히 읽지 못했다.

## 결론과 한계

- 놓친 픽 전부가 시즌 자료에 있었다. 시즌 카드의 별도 노출은 필요하나 이것만으로 순위 개선이 증명되지는 않는다.
- 상대 5픽을 모두 후보 목록에 포함한 4세트도 T1이 졌다. 후보 포함률은 밴픽 우위나 승리를 뜻하지 않는다.
- 주력 제거 검토 목록의 실제 픽 포함은 1/4였다. 다만 목록에 있던 카드가 T1에게 밴됐으면 실제 픽으로 나오지 못하므로, 이 수치를 밴 가치나 잘못된 밴의 비율로 해석해서는 안 된다.
- 예측 팩은 T1–KC와 BLG–DK 8강을 반영하지 않은 오래된 스냅샷이었다. 이것도 운영상의 한계다.
- 조합 상성, 선수 준비도, 인게임 실행을 이 채점으로 평가하지 않았다. 패배 원인을 밴픽으로 단정하지 않는다.

밴한 기록·현재 세트 밴·봇 듀오·조합 조건을 추가하고 다른 경기에서 확인해야 한다.
