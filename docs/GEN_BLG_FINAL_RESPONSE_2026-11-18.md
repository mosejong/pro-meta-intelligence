# GEN 실제 결승 선택에 대한 자동 BLG 반응 진단

2026-11-18 사용자 요청: 젠지의 월즈 결승 밴픽을 그대로 넣고 BLG의 자동 반응을 확인한다. 자동 상대 정책을 수정하거나 실제 BLG 답을 하드코딩하지 않고 현재 구현을 검사했다. 신규 배포 없음.

## 기록과 시점

수동 검토 참조: [1세트](https://leaguerecords.com/championships/worlds/2026/46/1), [2세트](https://leaguerecords.com/championships/worlds/2026/46/2), [3세트](https://leaguerecords.com/championships/worlds/2026/46/3), [4세트](https://leaguerecords.com/championships/worlds/2026/46/4), [시리즈/선수별 챔피언 목록](https://outdrafted.lol/lol/match/115660540726095133).

밴은 페이지가 연결하는 챔피언 이미지 파일명, 픽은 표시된 선택 순서를 대조했다. 공식 VOD 확인은 하지 않았다. 참조 페이지들의 패치 표기는26.20/16.20으로 달라 fixture에 각각 보존했다. 일반적인 패치 변환 규칙을 추가하지 않았다.

`web/tests/fixtures/worlds-final-gen-blg-20261114.json`은 이 요청의 수동 경기 참조다. 새 사이트를 상시 수집 출처나 학습 자료로 활성화하지 않았다. 기존 로컬 원본에 없는 최종 경기 CSV를 임의로 만들지 않았다.

두 보고서로 따로 검사했다.

1. `2026-11-14T00:19:10.467435+00:00` 기준 고정 공개 집계: 결승 시작19:00 UTC보다 이전 cutoff다. 이번에 fixture로 고정한 자료이며 당시 사전등록·봉인 증거를 확인한 것은 아니다.
2. 현재 공개 보고서 `2026-11-18T01:35:30.738564+00:00`: 두 팀 표본의 마지막 관측은 결승이 끝난11/14 23:18 UTC다. 사후 프로그램 동작 검사이며 사전 예측 검증으로 쓰지 않는다.

원문 자료/집계의 해시는 진단 산출물에 남긴다. 첫 세트~셋째 세트는 GEN 블루, 넷째는 BLG 블루다. 참조80턴과 실제 이전 세트 픽 잠금을 규칙 재생으로 검증했다.

## 1세트 결과

GEN 실제 픽: 리 신 → 신드라 → 올라프 → 코르키 → 나미.

| 구분 | BLG 밴 순서 | BLG 픽 순서 |
|---|---|---|
| 공개 결승 참조 | 키아나·카시오페아·룰루·이즈리얼·세라핀 | 레나타·칼리스타·Locke·크산테·자르반4세 |
| 결승 전 기준 보고서의 자동 상대 | 키아나·애쉬·세라핀·진·레오나 | 이즈리얼·노틸러스·나르·암베사·아리 |

결승 전 기준으로 GEN 선택10개를 유지한20턴을 완료했다. 공개 기록과 다른 선택은 실제 경기와 다른 가상 분기다. 관측 역할만으로 보아도 중복 역할/미충족 역할을 완전히 해결하지 못하며, 이 결과를 실제 BLG의 대응이나 좋은 조합이라고 주장하지 않는다.

현재 보고서를 쓰면 자동 BLG가 올라프 → 진 → 애쉬를 먼저 밴하고 나르 → 이즈리얼을 픽했다. GEN의 실제 세 번째 픽인 올라프를 넣을11번째 턴에서 차단된다. 10턴까지의 상태를 유지하고 멈췄다. 다른 챔피언으로 바꾸거나 잠금을 해제해 ‘같은 경기’로 완주시키지 않았다.

## 네 세트의 검사 방식

- **실제 prefix 응답:** BLG 각 차례마다 직전까지의 실제 경기 선택을 넣고 현재 정책의 한 선택을 비교한다. 총40차례. 다음 질문에는 이전 자동 선택을 이어 쓰지 않으므로 같은 후보가 여러 행에 나와도 실제로 중복 픽했다는 뜻은 아니다.
- **독립 세트 분기:** 해당 세트 이전의 실제 양팀 픽을 잠그고 GEN 실제 선택과 자동 BLG 선택을 이어간다. GEN 선택이 불가능해지면 중단한다. 네 세트가 이어지는 가상 시리즈가 아니다.
- **연속 가상 시리즈:** 앞선 자동 경기의 실제 생성 픽을 다음 세트 잠금으로 쓴다. 한번 GEN 선택이 차단되면 이후 세트도 진행하지 않는다.

| 결승 전 기준 독립 세트 | 진행 | 중단 이유 |
|---|---|---|
| 1세트 | 20/20 | 완료 |
| 2세트 | 2/20 | 자동 BLG가 키아나를 밴해 GEN의 다음 키아나 밴이 중복됨 |
| 3세트 | 17/20 | 자동 BLG가 라칸을 먼저 픽해 GEN의 실제 라칸 픽이 불가능 |
| 4세트 | 20/20 | 완료. 선택의 질을 보장하지 않음 |

연속 가상 시리즈도 결승 전 기준에서는2세트3번째 턴의 키아나 밴에서 중단됐다. 현재 보고서는1세트 올라프 선택에서 중단됐다. 실제 경기를 그대로 따라간다는 전제와 상대가 다르게 반응한다는 전제는 충돌할 수 있음을 확인했다.

실제 prefix40차례에서 결승 전 기준 정책은 실제 BLG 선택과4개, 현재 보고서는3개 일치했다. 이는 단일 시리즈의 선택 일치 수일 뿐 승패 예측 정확도나 코치 실력 평가가 아니다. 답과 다르다는 이유만으로 나쁜 밴픽이라고 단정하지 않는다.

## 원인과 다음 수정

현재 자동 상대는 `solo-draft.ts`에서 행동 팀/상대 팀의 `priority_picks`와 검토 가능한 레이더를 사용한다. 현재 BLG 우선 픽 요약은5행이며 Gnar/Ezreal/Jax/Viktor/K'Sante다. 정글·서포터 풀을 충분히 보지 못하고, 피어리스로 요약이 소진되면 이름순 목록 대체까지 내려간다. 현재 보고서의 실제 prefix 검사에서3세트2차례·4세트5차례가 이 대체 선택이었다.

반면 기존 BLG 스카우팅 팩에는5역할 시즌 기록이 있고, 선수별 챔피언 수는 Viper26·Xun20·Knight25·ON23·Bin20이다. **기록 부족과 자동 상대에 연결되지 않은 문제를 구분해야 한다.**

다음 수정 우선순위:

1. 같은 자료 기준으로 검증한 선수별 시즌·최근·패치 풀을 자동 상대에 연결한다. 사후 시즌 팩을 결승 전 평가에 섞지 않는다.
2. 남은5역할을 채울 수 있는지 전체 선택을 검사하고, 역할 힌트를 확정 역할/실력으로 바꾸지 않는다.
3. 픽과 밴의 우선순위 및 후보 소진 시 처리를 분리하고 목록 대체를 정상적인 팀 대응처럼 제시하지 않는다.
4. T1 상대 팩의 특수 deny/protect levers를 GEN 상대 행동으로 복사하지 않는다. 재사용 대상은 출처가 맞는 일반 선수 기록이다.
5. 이 결승은 개발 진단 사례로 보존한다. 수정 후 효용은 다른 팀·별도 경기에서도 검사한다. 한 결승의 정답을 외워 일치 수를 올리지 않는다.
