## 바뀐 동작

- 현재 레이더에서 검토 가능한 메타 후보를 먼저 확인하고, 중복 포지션 없이 배치 가능한 후보를 우선한다. 플렉스는 역할을 함께 매칭하며 실제 사용자 배정을 자동 확정하지 않는다.
- 현재 관측 선수의 정확한 팀 ID·선수 ID와 일치하는 시즌 역할 기록을 선택적으로 확장 후보에 쓴다. 시즌 숙련 기록과 현재 패치 강함을 구분한다. 가상 로스터는 자동 상대의 입력이 아니다.
- 시즌 파일은 자동 연습을 켰을 때 확인한다. 피드 기준/출처가 다르거나 요청이 실패하면 제외하고 기존 팀·레이더 후보로 진행한다. 시즌 파일 조회에는 기존 15초 제한이 적용된다.
- 역할 근거를 갖춘 선택을 못 찾으면 연습 자체는 이어가되 해당 자동 선택 설명에 포지션 근거 부족을 표시한다. 완성된 조합이나 실전 예측을 보장하지 않는다.
