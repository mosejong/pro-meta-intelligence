# 테스트 의견 남기기 · 2026-11-23

[한국어 지인 테스트판 계획](KOREAN_PREVIEW_TEST_PLAN.md)의 "받을 피드백" 항목을 앱 안의 의견 양식으로 옮겼다. 다음 작업 순서 6번(한국어 이용자 평가)을 준비하는 단계이며, 실제 참여자 모집이나 의견 수신을 한 것은 아니다.

## 이용 흐름

- 진입점 두 곳: 화면 맨 아래 고지 영역의 `테스트 의견 남기기`, 그리고 한 세트(20차례)를 마친 뒤 결과 아래 `한 세트 끝! 써보니 어땠나요?`. 친구 방에서는 세트 끝 안내를 띄우지 않는다.
- 질문(모두 선택 사항): 기기, 브라우저, 처음 1분 이해, 막힌 곳(여러 개), 그때 기대한 것, 저장·공유 범위, 실제 승률·능력으로 오해했는지, 다시 쓸 상황, 하나만 고친다면, 재사용 의향.
- `의견 복사` / `의견 파일로 저장`(pro-meta-test-feedback.txt). 테스터가 카카오톡 등으로 직접 보낸다. 클립보드가 막히면 직접 복사용 글상자를 띄운다.
- `지금 화면 상태도 함께 붙이기`(기본 켜짐, 내용을 그대로 미리 보여줌): 화면 단계·탭·진행 방식·완료 세트 수·현재 차례·패치·자료 기준 시각(분 단위 UTC)·화면 폭 구간. 정확한 픽셀 폭, 고른 챔피언·팀, 브라우저 식별 정보는 붙이지 않는다.

## 개인정보와 저장

- 네트워크 요청·분석 도구·외부 양식 서비스는 쓰지 않는다. 보낼 주소(`TESTER_FEEDBACK_EMAIL`)는 `null`이다. 실제로 확인하는 메일 주소를 정하면 그때 `메일 앱으로 보내기` 링크가 켜진다.
- 작성 중인 답만 이 브라우저의 localStorage(`pmi.testerFeedback.v1`)에 임시 보관한다. 화면 상태는 저장하지 않는다. 손상·다른 버전·과대 값은 무시하고 빈 양식으로 시작한다. 저장소가 막혀도 양식과 복사는 동작하며 안내를 띄운다.
- 자유 입력의 이메일·전화번호 형태는 글에서 `[연락처 지움]`으로 바꾸고 몇 곳을 지웠는지 알린다. 완전한 개인정보 탐지는 아니다.
- 지우기는 한 번 더 확인한 뒤 실행한다.
