# 한국어 비공개 사용 검사 준비 · 2026-11-19

목적은 기능동작 검사와 사람이 느끼는 재미/이해도/재방문 의도를 구분하는 것이다. 아직 참여자를 모집하거나 연락하지 않았다. 배포승인/외부공유를 대신하지 않는다.

한 사람이 안내문 없이 수행할 과제:
1. 양팀선택 후 자동상대 켜고1세트 완료. 막힌 지점과 도움요청 기록.
2. 선택이유/대안을 찾아 본인 말로 설명. 실제 프로대응 예측으로 오해하는지 확인.
3. 다음 피어리스 세트에서 잠긴 픽을 확인하고3세트 마치기.
4. 포지션을 직접 바꾸고 이름붙여저장, 새로열어복원.
5. 다른조건이면 가정비교를 거부하는 이유와 추상모델/실제경기 차이를 설명.

기록표: 익명참여ID/기기폭/과제/도움없이완료/막힌단계/오류/의미오해/다시쓰고싶은이유/다음날자발재방문. 주소·계정·실명·개인전적은 필요없다. 참여ID나 의견을 플레이어능력데이터로 쓰지 않는다.

조작을 대신해주면 독립완료가 아니라 도움받음으로 기록한다. 시간은 시작/끝을 직접 재되 사용자효용의 단독증거로 삼지 않는다. 유도질문 대신 마지막에 무엇을 더 해보고 싶은지 묻는다. 에이전트/자동브라우저 검사는 사전리허설이며 인간효용 입증으로 표시하지 않는다. 작은편의표본의 평가를 모집단통계/90%완성도 근거로 확대하지 않는다.
