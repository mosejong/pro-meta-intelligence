# C3c 결과 — 밴픽 정보의 추가 정보량 (오프라인, 탐색적)

2026-11-17. 고정 설계 1회 실행. 하이퍼파라미터 탐색·재튜닝 없음. 제품/ML 기능 아님, UI 미연결.

## 결론 (탐색적)

**이 자료와 이 고정 설계에서는 챔피언 가중치를 더한 모델(Elo+draft)이 팀 Elo보다 낫다는 관측이 없다.
따라서 밴픽 정보의 승패 예측 추가 효과는 미입증이다.**

- 전체(평가 2,695경기): Elo+draft가 logloss +0.0045, Brier +0.0018 더 나쁘고 accuracy −0.5%p.
- 일자 cluster bootstrap 95% 구간이 0을 포함 → "더 나쁘다"도 확정적이지 않다. 차이가 작고 방향은 불리.
- 집중 리그(WLDs/LCK/LEC/LPL) 모두 draft 쪽 logloss/Brier가 더 나쁘며 구간은 모두 0 포함.
- 이 결과는 실제 밴픽 변경의 인과 효과, 실제 승률, 시뮬레이터 보정 어느 것도 입증하지 않는다(나았더라도 마찬가지).

## 고정 설계

- 순차 walk-forward. 모든 경기는 observed_at 직전에 예측.
- 레이블 공개는 **시뮬레이션 지연** `observed_at + 24h`가 예측 대상 경기 observed_at보다 **엄격히 이를 때만** 반영(대기 큐).
  동일 시각 경기·정확히 +24h 경기는 서로의 레이블을 보지 못한다.
- 원본 `available_at`은 파일 전체의 bulk retrieval 시각이라 과거 공개 시각의 실측이 아니다. provenance는 변경하지 않았고,
  시뮬레이션 공개 시각은 별도 필드(`simulated_label_available_at`)로 분리했다. 당시 이 원본이 확보돼 있었다고 주장하지 않는다.
- Elo: 초기 1500, K 20, scale 400, 진영 이점 0. 업데이트 `K·(y − p_elo)`, p_elo는 그 경기 예측 당시 값.
- Elo+draft: `sigmoid(logit(p_elo) + Σblue w − Σred w)`. 초기 w=0, lr 0.03.
  레이블 반영 시 `p = sigmoid(예측 당시 Elo logit + 현재 가중치 margin)`, `err = y − p`;
  그 경기 픽 챔피언 가중치에 ×0.9999(L2) 후 blue `+lr·err`, red `−lr·err`. 다른 팀/선수 가중치 없음.
- 지표: accuracy(정확히 0.5 예측은 0.5점), logloss(극단값만 1e-12 clamp), Brier. 50% 기준 동시 보고.
- 일자(UTC) 단위 paired 차이(draft − Elo)의 경기당 평균, 1000회 일자 cluster bootstrap 95% 구간(seed 20261117).
  날짜 10일 미만이면 구간 미표시. 구간은 이 자료의 설명적 구간이며 재튜닝 검증이 아니다.
- 세그먼트 최소 표본 30경기(`sufficient_sample`). 모든 세그먼트는 같은 global 모델의 결과이며, 지역 간 차이를 인과로 해석하지 않는다.

## 결과

### 리그별 (상위, 전체 35개 중)

draft가 logloss에서 나았던 리그: LAS(288경기, −0.018), HC(99, −0.022), NACL(79, −0.039), NLC(73, −0.034), HM(86, −0.005).

리그별 구간은 집중 리그 외에는 계산하지 않았고, 여러 세그먼트를 본 만큼 일부의 우세는 우연일 수 있다.

## 한계

- 원본 1개 스냅샷, 11/09까지. 24h 지연은 시뮬레이션 가정이며 실제 공개 이력이 아니다.
- 챔피언 가중치는 팀 맥락·상대 조합·역할·패치를 모르는 전역 단일 가중치다. 이 단순 형태가 실패했다고 해서
  밴픽 정보 전체가 무가치하다는 뜻은 아니며, 반대로 다른 형태를 지금 결과를 보고 고르면 사후 탐색이 된다.
- 픽은 팀 실력과 상관(강팀이 고르는 챔피언)되어 Elo와 중복 정보일 수 있다. 인과 효과 식별 불가.
- 국제전(WLDs)은 지역 간 Elo 연결이 약해 기본값 자체가 불안정하다.
- 어댑터 거부 642경기(대부분 팀 ID 누락)는 리그별로 편중될 수 있다.
