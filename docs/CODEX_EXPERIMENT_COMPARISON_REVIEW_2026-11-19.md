# 가정 실험 A/B 비교 · Codex 독립 검토

Claude Opus 5.5 medium 구현/수정, Codex 독립 검토. 제품 기능은 로컬이며 공개하지 않았다.

## 범위와 제한

완료한 실행을 분리·동결한 기준 A로 보관하고, 같은 고정 밴픽·선수·역할·자료·규칙·재현 번호의 실행 B와 가정값 및 모델 결과 차이를 비교한다. 여러 가정을 바꾸면 단일 원인으로 나누지 않는다. B 종료 전에는 결과 차이를 숨기고 되감으면 다시 숨긴다. 팀은 표시 이름이나 진영이 아니라 원본 ID로 대응한다. 기준 교체·해제는 명시 조작이며 현재 밴픽과 재생은 보존한다.

선수·챔피언·시대·아이템·룬의 실제 효과는 아직 모델에 없다. 실제 승률, 인과 효과, 선수 기여도나 추천 효용 검증이 아니다. 실행과 기준 A는 화면 메모리 전용이며 파일 가져오기·새 저장 형식을 추가하지 않았다.

## 발견한 결함과 수정

초기 비교 구현은 변조 검사를 위해 기준 복사와 화면 비교 때마다 `simulateManager`를 호출했다. Codex가 실제 함수에 호출 계측을 넣어 명시 실행 2회가 7회로 늘어나는 실패를 재현했다. 해당 회귀 검사를 바꾸지 않고 Claude에 수정을 맡겼다.

현재는 모듈 내부 WeakSet으로 직접 생성한 깊게 동결된 실행과 신뢰된 복사만 인정한다. 기준 복사·비교·재생·화면 갱신은 모델을 호출하지 않는다. 같은 내용의 JSON 왕복·structuredClone·수기 객체도 이 화면의 직접 실행이 아니므로 UNTRUSTED로 거부한다. 외부 실행 파일 검증 기능으로 오해하지 않는다. 모델 호출은 명시 실행 2회 그대로임을 독립 회귀에서 확인했다.
