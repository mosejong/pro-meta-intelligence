# 최신 경기와 시리즈 근거 점검

확인일: 2026-11-07. 아래는 조회한 경기 사실이며, 자동 수집한 OE 기록을 대체하지 않는다.

- [공식 Worlds 일정](https://lolesports.com/en-US/leagues/worlds)은 T1–KC 3:1과
  T1–BLG 준결승 대진을 표시한다.
- [세트별 경기 페이지](https://esport.vision/lol/match/115660540726095103-t1-vs-karmine-corp)는
  T1–KC를 네 세트로 나누고 각각 역할별 픽을 제시한다. 공급자 경기 ID와의 연결은 미완료다.
- 이 페이지의 1~4세트 픽은 기존 잠정 채점 스크립트에 입력한 픽 목록과 일치했다.
  단, 경기 시간 초 단위는 다른 사이트와 다르므로 자동 식별 키로 쓰지 않는다.
- [Game of Legends](https://gol.gg/game/stats/83709/page-preview/) 검색 결과는 해당 대진을
  보여 주지만 경기 상세 조회는 실패했다. 그것만으로 공급자 세트 ID를 확정하지 않았다.

## 확보한 것 / 아직 없는 것

확보: 공식 시리즈 결과·다음 상대, 다른 공개 기록과 일치하는 네 세트의 역할별 픽.
아직 없음: 최신 OE CSV의 해당 경기 행, 그 행의 게임 ID와 외부 세트 번호를 잇는 검증된 교차표,
공식 영상 기준 전체 밴픽 순서 확인, 팀 전체 시즌의 검증된 시리즈·세트 교차표.

새 파일 수집은 11월 7일 08:46 UTC 시도에서 Google Drive가 CSV 대신 HTML을 반환했다.
같은 날 제한을 회피해 반복 요청하지 않는다. 11월 8일 08:46 UTC 이후가 그 시도 기준
다음 가능 시각이며 다른 수집기의 더 늦은 시도가 있으면 그 시각도 따라야 한다.
기존 스카우팅 팩은 11월 4일 수집본임을 유지한다.

## 적용한 방어

기존 백테스트의 12시간 시리즈 추정에 상대 팀 쌍·리그 동일 조건을 추가했다.
가까운 시간에 다른 상대와 한 경기를 한 시리즈로 묶어 피어리스 잠금을 전파하지 않는다.
여전히 시간 기반 추정이므로 공식 시리즈 ID를 확보했다고 표시하지 않는다.
새 파일을 확보하면 공식 대진·양 팀·역할별 픽을 대조해 세트 번호를 연결하고,
중복 후보나 누락이 있으면 연결을 보류해야 한다.
