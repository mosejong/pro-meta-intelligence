# 비공개 개발 및 출시 판단 기준

2026-11-17 사용자 결정: 공개를 서두르지 않는다. 한국어와 중국어 간체를 지원하고
핵심 사용 흐름의 완성도를 높인 뒤 공개 여부를 판단한다. 현재 공개 배포된 기존
사이트의 상태와 이번 로컬 개발본의 상태는 구분한다. 이 문서는 배포 승인이 아니다.

## 90%의 의미

단순 작업 개수나 예측 적중률을 제품 완성도로 부르지 않는다. 아래 필수 관문이
미충족이면 출시 후보로 보지 않는다. 각 항목은 실제 검사 날짜와 증거를 남긴다.

| 관문 | 필요한 증거 | 현재 |
|---|---|---|
| 밴픽 | 양 진영 전체 진행, 되돌리기, 세트 전환, 잠금, 저장·복원 | 실제 Chrome PC·모바일 폭 검사 있음. 실제 기기·전면 Tab 탐색은 미검증 |
| 한국어·중국어 간체 | 주요 흐름·오류·접근성 문구 번역, 공식 명칭 대조, 원어민 검토 | 기존 메뉴/밴픽 기반 있음. 새 선수·연간 기능은 한국어, 기능 검증 후 번역 |
| 사용성 | PC·모바일 실제 조작, 가려짐·터치·키보드·긴 문구 점검 | Chrome 폭별 조작·실패 주입 근거 있음. 네트워크 지연/로딩 경합 보완 중 |
| 분석 | 출처·패치·표본·누락 표시, 팀 불일치 방지, 별도 평가 자료 검증 | 219프로필 역할·범위 678개 독립 대조. 추천/승패 효용 입증은 아님 |
| 룬·아이템 | 허용된 자료 접근, 정적 목록과 실제 빌드 구분, 구도별 근거 | 미연결 |
| 시뮬레이션 | 재현성·지원 범위·비교 근거·불확실성 및 외부 평가 | 설계 단계 |
| 운영 | 갱신 실패 복구, 저장 호환성, 오류 관측, 실제 접속 확인 | 기존 C1 배포 화면 확인. 연간 자동 갱신은 로컬 검사 완료, 서버 실행은 미확인 |
| 중국 이용 환경 | 실제 지역에서 접속·자산 로딩·링크 공유 검증 | 미검증 |

## 실행 순서

1. 핵심 로딩·저장·복구와 자료 경합을 보완해 조작이 막히거나 기준이 섞이는 문제를 먼저 해결한다.
2. 로스터/선수 근거를 포함하는 시나리오 입력·A/B 비교 계약을 검증한다. 기존 파일 호환을 유지한다.
3. 최소 시뮬레이션을 지원 범위·가정·시드·규칙 버전과 함께 구현/검증한다. 실제 승률로 표시하지 않는다.
4. 권한과 관측 근거가 확보된 구도별 룬·아이템 자료를 연결한다. 빈 자료를 가짜 추천으로 채우지 않는다.
5. **완성된 기능에만** 별도 번역 담당을 붙인다. 공식 중국어 명칭 대조와 양 언어 PC/모바일 검사를 한다.
6. 서버 운영·중국 실제 접속·실제 사용자 효용을 확인한 뒤 출시 여부를 판단한다.
7. 공개 뒤 국가별 집계 방문·밴픽 완료·재방문을 확인하고 홍보 및 인프라 투자를 판단한다.

현재 공개 사이트에 배포된 C1과 로컬의 선수 근거/연간 관측/자동 갱신 개선을 구분한다.
로컬 검사 통과를 서버 반영이나 출시 승인으로 대신하지 않는다. 완성도는 위 필수 관문별로
판단하며 테스트 수나 임의의 백분율로 계산하지 않는다.

국가별 트래픽은 집계 수준에서 다루며 정확한 신원·플레이어 계정 자료와 결합하지 않는다.
집계 방식, 동의·보관 조건과 실제 중국 접속 환경은 제공자 선정 시 검토한다.
현재 서버/도메인 구매, 광고 도입, 원격 방 서비스 가입은 실행하지 않는다.
