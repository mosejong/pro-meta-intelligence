# 연습과 현재 선수 구성 함께 보관 · 구현 체크포인트

2026-11-19 · Claude Opus5.5 medium 구현 / Codex 연결·짧은 핵심 확인.

## 추가한 흐름

내 연습 보관함에서 '현재 선수 구성도 함께 저장'을 선택하면 밴픽·이전세트·직접 배정 포지션과 현재 공개 스냅샷의 가상 선수 구성을 함께 보관한다. 기존 v1 항목은 그대로 읽으며 draft-session/roster-scenario 파일 형식과 DB 버전은 변경하지 않았다. 새 번들은 기준·팀·선수 ID와 메타데이터 일치를 확인하고 일부가 손상되면 통째로 거부한다.

같은 팀·같은 자료 기준이어도 저장한 구성이 다시 적용된다. 구버전 기기 로스터의 늦은 읽기가 덮어쓰지 못하게 복원 요청을 전달하고, 중간에는 선수 로스터를 준비 완료로 내보내지 않는다. 이전 항목에 로스터가 없으면 기존 동작을 유지한다.

시즌 선수·감코·가정 실험·기준 A·자동 설명 이력·방 credentials는 포함하지 않는다. 역사 시즌 선수가 있으면 함께 저장을 차단하고 기존 구단 저장 안내를 제공한다. 사용자가 명시적으로 밴픽만 저장하는 것은 가능하다.

## 확인 범위

- 새 번들/기존 보관함 핵심10개, 타입 및 변경 파일 lint 통과.
- 실제 Chrome에서 저장→현재 선수 구성 변경→같은 연습 불러오기→원래 선수와 밴픽 동시 복원 1개 통과. PC 한 경로이며 모바일·경합 전수 검사는 다음 통합으로 남긴다.
- 초기 손상 거부 검사는 실패했으나 원인은 테스트 대역의 이전 Map 참조였다. 새 save 뒤 현재 store Map을 다시 읽어 변조했고 같은 CORRUPT 기대값을 유지한 채 통과했다. 이를 제품 정합 검사 결함 수정으로 부르지 않는다.
- 새 unit을 일반 검사 목록에 등록했으나 전체 npm/Python/Pages 전수는 반복하지 않았다. 브라우저 실행을 위한 Pages 빌드만 했다.
