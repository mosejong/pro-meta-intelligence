# 실시간 밴픽방 v1 검증 결과

2026-11-18. 구현과 검증은 로컬이며 공개 서버에 배포하지 않았다.

## 구현

독립 Node HTTP 서버가 팀·턴·챔피언·피어리스·revision을 검증한다. 방장은 블루, 초대받은 첫 참가자는 레드, 관전자는 읽기 전용이다. 초대 링크와 관전 링크를 나눴고 방장 토큰은 공유 링크에 포함하지 않는다. 인증 헤더로 NDJSON 상태를 구독하며 새로고침 복귀와 연결 복구를 지원한다.

개인 연습은 유지한다. 참여는 명시적으로 확인하며 방 안에서는 로컬 팀 변경·되돌리기·파일 가져오기로 공동 밴픽을 갈라놓을 수 없다. 나가면 마지막 보드를 개인 연습으로 이어간다. 팀·밴픽만 공유하고 선수 변경·역할 배정은 공유하지 않는다.

## 실행 결과

| 검사 | 결과 |
|---|---|
| 기본 웹 전체 테스트 | 204/204 통과 |
| 방 store/client/실제 HTTP 통합 | 19/19 통과 |
| 최종 client 보완 후 재검사 | 11/11 통과 |
| 최종 TypeScript / ESLint | 통과 |
| 일반 정적 Pages 검사 | 4/4 통과 |
| 실제 서버와 PC·모바일 브라우저 | 6/6 통과 |

브라우저는 실제 HTTP 서버와 별도 블루·레드·관전자 컨텍스트를 사용했다. 양 진영 번갈아 20턴 완료, 관전자·상대 차례 조작 잠금, 방장·레드 새로고침 복귀, 오프라인 입력 잠금·재접속, 다음 세트의 양 팀 픽 10개 잠금, 나간 뒤 개인 연습 유지, 생성 취소, 나간 후 늦은 클립보드 완료 무시를 확인했다. 모바일은 Playwright의 모바일 폭·터치 에뮬레이션이며 실제 휴대폰·외부망 검증은 아니다.

별도 서버 코드 검토에서 문자열 아닌 action kind가 초기화로 처리될 수 있는 결함을 찾아 엄격한 타입 검사와 회귀 테스트를 추가했다. 실제 브라우저 첫 검사에서는 기본 fetch를 클래스 메서드로 호출한 수신자 문제를 발견해 래퍼로 고쳤다. 두 번째 검사에서 오프라인 전환 시 진행 중 스트림이 즉시 끊기지 않아 연결 상태가 남는 문제를 발견했고 online/offline 이벤트로 구독을 갱신하도록 보완했다. 보완 후 PC·모바일 6개를 모두 통과했다.

전체 웹 204개와 방 통합 19개는 최종 브라우저 보완 전 실행이었다. 최종 변경에는 client 11개·타입·린트·실제 브라우저 6개로 해당 범위를 다시 검사했다. Python 코드는 바꾸지 않았고 이 배치에서 Python 테스트는 재실행하지 않았다.

로그: `outputs/realtime-room-{web-full,server-final,client-final,typecheck-final,lint-final,e2e}-20261118.log`, `outputs/realtime-room-pages-tests-20261118.log`.

화면: `outputs/realtime-room-ui-20261118/` 아래 PC·모바일 각각 `completed-draft.png`, `spectator-draft.png`. 모바일 완료 화면도 열어 배치와 표시를 확인했다.

## 실행과 한계

`web/`에서 `npm run build:room`, `npm run start:room`. 서버 기본 주소는 loopback 4271이다. 프런트 빌드의 `VITE_DRAFT_ROOM_ENDPOINT`와 `DRAFT_ROOM_ALLOWED_ORIGINS`를 일치시킨다. 일반 빌드는 endpoint가 없어서 실시간 방 준비 안내와 기존 링크 공유를 제공한다. 로컬 검사 전용 빌드는 `dist-room-pages`로 분리했다.

방은 임시 메모리이며 2시간 후 만료하고 서버 재시작 시 사라진다. 단일 프로세스·최대 200방·방당 최대 24구독·IP당 시간당 생성 10회·본문 16KiB 제한이다. 운영용 영속 DB, 외부 HTTPS, 분산 서버, 계정과 구단 저장은 아직 없다. 프런트와 서버 공개 보고서의 패치·기준 시점이 같아야 한다. 자료 갱신에 따른 운영 전환도 후속 과제다.

다음 구현은 게스트 구단 저장과 5역할 선수 구성이다. 로그인 버튼, 코치의 가짜 능력치, 실제 경기 승률을 이 배치의 완료로 주장하지 않는다.
