# 최소 매니저 엔진 — 내부 실험

2026-11-17. `web/app/simulation-core.ts`는 아직 화면이나 실제 밴픽 결과와 연결하지 않은 내부 기반이다.
게임 운영·자원·교전·오브젝트·기지·종료의 상태 전이를 먼저 검증한다.

## 입력·규칙

- 규칙 `assumption-manager-v1`, 32비트 정수 시드, 서로 다른 팀 ID 2개.
- 팀별 라인/템포/한타 가정 -1..1. 모두 **사용자 가정**이며 선수·챔피언 자료에서 추정하지 않는다.
- 매 분 추상 자원 성장. 6분부터 3분마다 교전, 승자 자원·오브젝트 증가. 18분 이후 조건을 충족하면 기지에 피해.
- 기지 파괴 또는 45분 자원·기지 기준 판정으로 반드시 끝난다. 동점 최종 판정은 안정된 팀 ID 순서다.
- 성장/교전/보상/피해의 계수는 작성한 규칙이다. 실제 패치 수치·드래곤·타워의 재현이 아니다.
- 진영은 표시 순서이며 블루 우위를 넣지 않았다. 같은 ID·가정·시드를 유지하고 순서를 바꾸면 사건과 승자가 같다.
- 내보내기와 읽기 전용 재현은 입력으로 결과를 재계산한다. 저장된 승자·사건·모델 버전을 신뢰하지 않는다.

## 구현 관문

- 500시드의 종료/시간 순서/정수·비음수/이벤트별 자원·킬·기지 합계/진영 교환 대칭을 검사한다.
- 동일 시드 재현, 입력 불변·참조 분리, 극단 가정 민감도, 잘못된 입력·초과 크기·결과 변조 거부를 검사한다.
- 단위 검사 5개이며 내부에 500시드 불변식과 200시드 가정 민감도가 있다. 테스트 수를 정확도/실제 경기 수로 세지 않는다.
- 결과 로그: `outputs/simulation-core-unit-20261117.log` (5/5 통과). 해당 모듈을 포함한 웹 전체 143/143, 타입·린트도 통과했다 (`outputs/roster-comparison-*-20261117.log`).

## 아직 안 하는 것

실제 선수·챔피언·상성·룬·아이템 효과를 계산하지 않는다. 승자를 출력한다는 이유로 예측 모델이 완성됐다고 하지 않는다.
현재 승자를 밴픽 화면에 붙이면 사용자에게 잘못된 의미를 줄 수 있어 **아직 연결하지 않는다**.
연결 전 입력에서 관측과 가정을 분리하고, 챔피언 역할 배정/지원 범위/데이터 없음/규칙 버전을 고정해야 한다.
실제 예측으로 발전시키려면 경기 전 기준 시점 자료와 별도 검증 세트, 기본 모델 대비 성능·보정·불확실성 검사가 필요하다.

이 기반은 현재 A/B 로스터 연결 작업과 파일 소유를 분리했다. 추천 가중치·기존 밴픽 저장·기기 저장·자동 갱신은 변경하지 않는다.
